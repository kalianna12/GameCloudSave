Playnite 游戏库只读，不修改原库；本地扫描不运行候选文件。导入、目录和封面匹配评分仅供参考。恢复前保留当前存档，重要进度请另保留备份。

密码、DeepSeek Key 使用当前 Windows 用户的 DPAPI 保存。开启联网功能时，会向所选服务发送搜索名称或候选目录/文件名，不发送存档内容给 AI。上传云端由用户设置和操作控制。

拼音与首字母搜索使用 pypinyin 0.55.0（MIT，mozillazg，https://github.com/mozillazg/python-pinyin）。中文录入调用 Windows 上已安装的输入法。
