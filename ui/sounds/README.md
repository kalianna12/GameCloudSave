# 导航提示音

12 个短音均由本项目的 `scripts/generate_navigation_sounds.py` 合成，不含第三方游戏或主机的录音采样，不需要额外音效包。

三种音色保留 `clear`、`soft`、`arcade` 设置编号；移动、确认、返回、打开各有独立音效。本轮降低基频和峰值，采用约 10ms 起音、22ms 收尾及重叠音符，避免突变和高频谐波造成的刺耳感。使用已有音量选项调整响度。

运行时由 `app/navigation_audio.py` 预载、按设备格式转换并混音。快速操作保留上一声尾音，使用平滑限幅；应用在前台且启用声音时维持静音流，避免导航间隔较长时反复启动输出设备。切换到后台、关闭声音或静音后释放输出。`navigation.wav` 是旧资源，目前导航不使用它。
