# V1.3 界面与高分屏

## 使用

关闭旧窗口，运行上级目录的“启动新版.bat”。启动器优先选择 V1.3，V1.2 二进制仍保留。游戏库、电脑配置和云端文件夹沿用现有数据。

## 界面

以用户提供的 Xbox PC 游戏库截图为参考：中性深灰、朴素导航、封面优先。参考并安装 [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，实际界面使用 Qt Quick。

背景 #1b1c1e，导航 #242629，面板 #27292c，边界 #45494e，正文 #f0f1f2，次要文字 #a6a9ae，操作强调 #80c942。字体使用 Windows 中文界面字体 Microsoft YaHei UI；标题 24–28，正文 13，辅助文字 11。按钮圆角 5，游戏卡片圆角 6。

首页去掉宣传横幅、英文口号和重复入口。左侧为游戏库、云端存储、查找存档、设置。每个游戏保留大封面、两行名称、状态及启动 / 设置 / 云存档 / 移除四个操作。移除只删除管理条目。

“查找存档”直接显示找到的目录与存档文件；别名、匹配度和其他可能位置放进“匹配详情”。DeepSeek 连接选项放进“匹配设置”。手动选择仍优先打开自动候选目录。

## 清晰度与性能

SVG 按屏幕缩放倍率生成实际像素尺寸，避免把固定 20 像素的图标放大。按钮保留加载 / 成功 / 失败状态，取消悬停缩放和摇晃。

封面使用普通与高清两级磁盘缓存。根据显示尺寸按 360 / 720 / 1080 像素分档解码，异步加载，继续复用滚动项目。缓存命中不解码、不重写索引；源图变化自动生成新缓存。高清缓存不把小图片强行放大；实际细节受 Playnite 原图限制。

搜索增加 120 毫秒输入等待；Esc 清空搜索。显示大小、列数和间隔仍可调整，布局变动与状态变动不重建游戏数据。

## 验证

27 个核心 / 迭代 / 工作流测试通过，后台监听测试通过。新增离线界面检查覆盖 900×680、小窗口、桌面布局及 3840×2160 实际渲染，检查搜索、手动目录、设置、匹配及 DAV 表单；无 QML 警告。

本机 150% 缩放 4K 滚动检查：帧间隔中位数 16 毫秒，95 分位 16 毫秒，游戏模型重建 0 次；热缓存准备约 33 毫秒。150% / 200% 缩放下，20 个游戏操作图标像素中心检查通过。数值反映本机此次测试，不代表所有硬件。

此轮功能回归使用隔离备份数据，界面测试不访问 DAV，也不修改真实游戏存档。独立打包后额外验证本地备份、恢复、中文 JSON、SQLite、DPAPI 和自带 rclone。
