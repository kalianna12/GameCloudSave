# 首页游戏推荐

2026-10-17，源码新增商店推荐。没有更新便携版、安装包或 GitHub 发行文件。

## 使用

重启 `workspace/启动源码版.bat`。原版首页在最近游玩之后显示：新发布、正在促销、Steam 热门、Xbox 精选。首次使用尚未导入游戏时，也可以浏览推荐。

点击卡片或手柄 A 打开官方商品宣传页；“查看商店”打开对应集合。方向键切换，肩键翻页。商店卡片没有本地游戏的启动、收藏和存档功能，不会把商店游戏自动写入游戏库。

栏目旁的“刷新”只更新该栏目，其他栏目保持原样；只在当前栏目显示加载状态。保留已显示图片，等新图就绪再替换，滚动位置和选中项不重置。相同游戏同时出现在新发布和促销中时，局部刷新也不会顺带修改另一栏。Steam 的接口一次返回多种列表，但这里只应用用户点击的那一栏，并只为它补图；定时刷新仍用于更新全部来源。

“设置 → 游戏库 → 首页游戏推荐”默认开启，可以整体关闭，或分别关闭 Steam、Xbox。Steam 使用国区、人民币价格，Xbox 使用港区并标出 PC/Xbox 及港区信息，港币显示 `HK$`。不换算货币。

书柜、影院、星图保留现有游戏排列，通过顶部“游戏推荐”打开同样的推荐陈列，手柄可进入并按 B 返回。推荐页按需创建，关闭后释放内容，不在后台重复维护一套隐藏卡片。

## 来源与含义

- Steam 直接读取[官方商店公开数据](https://store.steampowered.com/api/featuredcategories/?cc=cn&l=schinese)中的 `new_releases`、`specials` 和 `top_sellers`。过滤非 Windows、非单游戏类型及列表内重复项，每组最多 10 款。“Steam 热门”依据热销顺序，不是同时在线人数排名；它也可能包含预购商品。
- Xbox 读取[官方商店目录页面](https://www.xbox.com/zh-HK/games/browse)附带的结构化商品数据，保留其目录顺序，每组最多 10 款；读取标题、宣传图片、支持设备、公开价格和折扣。不执行页面脚本。此处称“Xbox 精选”，不把普通目录冒充新发布或热销排行。旧版独立推荐接口在当前网络下未能连接，本轮未依赖它。
- 使用匿名商店价格，不把订阅会员专享价格显示为所有用户均可享有的价格。未提供价格时显示“查看商店”，不会把缺价当免费。

这不是账号个性化推荐，不需要登录 Steam、Xbox 或填写 API Key；不会上传本机游戏库、游玩记录、存档或现有密钥。此轮接入 Steam、Xbox 两个来源，未增加其他平台。

公开商店接口和页面结构可能改变。两个来源分别处理故障，一个失败时另一个仍可显示；错误可在设置中查看，并可从陈列标题旁刷新。结算价格和可购状态以商品页为准。

## 视觉与交互

沿用现有主题令牌、微软雅黑字体和字号层级、标题左对齐、横向陈列、封面扫光、指针倾斜、强调色焦点与平滑翻页。碳灰默认令牌为背景 `#181a1c`、侧栏 `#202326`、表面 `#282c30`、正文 `#f3f5f7`、次要文字 `#a9b4bf`、强调色 `#80c942`；切主题后全部跟随现有配色，不额外锁定一套商店颜色。

推荐使用官方横向宣传图，避免新发布游戏没有竖封面时，强裁横图导致标题和主体缺失。平台放在图片下沿，价格放在标题下方，促销显示折扣和划线原价。图片加载前保留游戏名占位，失败不影响点击商品页。大小和间距跟随首页布局设置，关闭界面动效时尊重原设置。

## 并发、缓存与关闭

- 独立 2 个商店资料线程和 4 个图片线程，不占用主界面线程，也不占用备份任务队列。每个来源完成即显示；图片逐项更新，不等待最慢的一张。
- 同一游戏跨栏目出现时只请求一次图片；不同商品共用一张图也合并下载。图片限制响应大小、尺寸，缩小后本地缓存，损坏缓存重新下载。
- 目录缓存一小时，运行期间每小时刷新，也可手动刷新。七天内的旧缓存可供断网使用；过期价格和折扣隐藏为“价格待刷新”，已知到期的促销不再显示。
- 商店图片缓存与游戏库封面、存档完全分开；超过 160 张且一天以上未使用的缓存可被清理，正在使用的图片更新访问时间。
- 关闭总开关或来源开关后，取消后续任务并丢弃旧结果；已经发出的网络请求最多等自身超时结束，不再应用到界面。应用退出时停止刷新定时器并取消排队任务。

## 验证

所有源码测试使用隔离数据，真实源码配置/游戏库等 287 个文件与发布基线哈希一致；没有启动真实游戏、写入真实云存档或打开浏览器商品页。

- 63 项单元/算法检查通过：推荐 12 项及监听、恢复、游戏库和主题分组相关回归。涵盖价格/币种、会员价、来源格式、并发独立失败、禁用后迟到回调、缓存、促销到期和链接限制。
- `tests/test_recommendations_ui.py`：慢 Xbox 不阻塞 Steam，Qt 心跳继续；图片后台获取与合并下载、空游戏库、鼠标/模拟手柄商品跳转、其他布局入口、浅色/900 像素、关闭开关通过。
- 首页布局、首页退出上传状态、四种布局手柄导航三组独立界面回归通过。
- `tests/live_recommendations.py` 匿名实连两家官方商店：首批资料约 0.69 秒，全部 37 张图片约 9.45 秒；新发布 10、促销 10、Steam 热门 7、Xbox 精选 10。数据和耗时仅代表本次请求，未伪造空缺数量。

实连脚本需要手动运行，普通测试不自动访问真实商店。报告和截图在忽略提交的 `test-data/recommendations/`，包括 `live-result.json`、`live-dark.png`、`live-light-small.png`。
