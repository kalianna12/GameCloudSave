# 本地成就增强、统计总览与单行工具栏

2026-10-23，源码版。此文更新上一轮 [非 Steam 成就调查](非Steam成就来源与徽标显示.md) 中的支持范围；没有打包、同步便携版或发布。

## 用户可见变化

- 游戏库顶部的安装、平台、来源、筛选、随机、排序、映射、布局、个性化、全屏保持同一行。窄窗口可以横向滚动；手柄或键盘焦点移到边缘控件时，自动把它滚入视野。900／1100／1440／1920 宽度和实际全屏均验证同一行。
- 成就管理参照提供的图片：左侧游戏封面、完成数和进度条，右侧每项独立图标、说明、日期、稀有度、计数进度条。已有定义时收起匹配表单；列表支持筛选、排序、隐藏内容开关。选中颜色有短过渡动画。
- 游戏与成就页下方显示完成度环形图、柱状图和时间曲线，窗口高度不足时通过“统计总览”查看。可切换全部／单款游戏、7／30／90 天／一年／全部时间、期间或累计曲线；鼠标悬停显示对应日期／分类数值。
- 统计区使用真实进度快照，不生成展示用解锁。未知日期计入完成数，排除在时间曲线外；未知全球解锁率单列“未知”。长时间范围按桶合计，标签注明桶大小。图表仅在内容变化或显示时做 320ms 动画，遵守界面动效开关；图标缓存进度更新不会反复重算统计或重启动画。
- 图标仍按整套后台缓存，打开／重试时补齐失败项。最近解锁页也使用对应成就图标。

## 这三款游戏实际检查了什么

只读读取已有游戏条目、已配置的游戏／存档目录和常见 App ID 目录；使用隔离 Store 和独立缓存测试界面。没有运行真实游戏或改动游戏文件。三款游戏均从公开 Steam 定义得到列表，并额外实际读取 Steam Community 新页面，核对内部 ID 集合一致：

| 游戏 | App ID | 成就及独立图标 | 本机记录结果 |
| --- | --- | --- | --- |
| The First Berserker: Khazan | 2680010 | 57／57 | 未发现支持的成就记录；已有 GVAS 存档不能直接当作成就日志 |
| Silent Hill f | 2947440 | 56／56 | RUNE `achievements.ini` 存在，内容为 `[SteamAchievements] Count=0` |
| The Last of Us Part II Remastered | 2531310 | 45／45 | RUNE `achievements.ini` 为 Count=0；另有 `stats.ini` 的 UserStats 数值统计 |

158 个图标全部下载到工作区隔离缓存，并逐个用 QImage 解码通过；不是重复的星形占位图。第一次下载有一个 CDN 请求短暂失败，续补后达到全量。截图和验证结果：`build/achievement-game-review/`。

**修复了真实误判**：旧逻辑可能把 UserStats 中值为 1 的普通统计当作已解锁成就。现在只读取明确的成就字段；发现旧源是普通统计时改用真正的成就记录，保留旧命名空间供回溯，不修改原文件。Count=0 则作为合法空容器保留，启动后监听首次解锁。测试验证了空容器写入第一项后产生新解锁事件。

这不代表上述游戏已经完成真实游玩解锁实测。目前读取到的两份 RUNE 记录确实为空，卡赞没有可读记录；程序不会把普通存档内容、数值统计或 AI 推断当作已经解锁。

## 多源与本地格式

自动定义来源：Steam → 已有本地定义／Steam 缓存 → SteamHunters → Steam Community → Completionist.me。也可以手动指定来源。

- Steam Community：适配当前 `valve-ssr-data` 中带内部 ID 的定义，实际核对三款游戏均成功；没有按 HTML 行序号猜测 API 名称。
- Completionist.me：参考项目中的额外匿名来源，按唯一标题／图标关联已有内部 ID；没有对应关系时标记为标题来源，不能强行匹配 API 进度，也不能导出成运行环境定义包。当前网络返回 HTTP 403，已按失败处理；其页面格式用独立夹具测试，不能宣称本机已联网成功。
- SteamHunters 在此前本机测试也出现 403，自动模式保留缓存并继续回退，不绕过站点访问限制。
- DeepSeek：实际使用现有加密凭据辅助核对了三款名称。模型未提供可验证的新记录路径，建议没有被采纳为解锁证据。界面新增“DeepSeek 匹配”，只影响名称／版本搜索，最终版本由用户确认；不生成进度或虚构徽标。
- 新增独立的 SmartSteamEmu `stats.bin` 解析：4 字节数量头、24 字节条目、CRC32 对应定义内部 ID；只接受 0／1 标志且必须唯一对应定义，其他统计不作为成就。
- 本地扫描扩展至深层 UE Steamworks 目录，支持读取 TENOKE 的 `ACHIEVEMENTS.*` 节和已有的兼容 JSON／INI；保持数量／大小限制、重解析点过滤及后台串行读取。
- GOG Galaxy、模拟器奖杯、游戏私有 GVAS／USR-DATA 等格式尚未适配。不能只凭某个平台有成就列表，就把它当作可读取的本机进度。

## 成就定义包

“匹配与记录设置 → 导出成就定义包”把内部 ID、名称、说明、隐藏标志和已缓存的独立图标导出到本程序 `achievements/exports/<AppID>/` 下，结构为 `steam_settings/achievements.json` 与 `img/`。标题来源缺少内部 ID 时拒绝导出。API 名称不用于文件路径，图标文件使用哈希命名。

本轮已经在工作区准备了三份真实定义包：

- `build/achievement-game-review/definition-packs/2680010/`
- `build/achievement-game-review/definition-packs/2947440/`
- `build/achievement-game-review/definition-packs/2531310/`

只包含定义和图片，不包含运行库、DLL 或解锁记录，不自动安装或修改游戏。是否能让游戏输出日志取决于其既有运行环境；导出成功不等于该版本已经支持解锁。没有为了生成记录替换任何游戏运行库。

## 验证和性能

- 29 项独立单元测试：原有解析／来源、增加的 SSE、RUNE 空容器、普通统计排除、深层目录、Community SSR、Completionist 标题边界、统计日期／稀有度／空数据和安全导出。
- 异步回归：旧响应隔离、断网保留缓存、监听不被网络阻塞、断写重试、首次创建记录和首次 RUNE 解锁、DeepSeek 开关传递。
- 实际 QML：四布局徽标、成就管理、搜索／筛选、900px 和大窗口、统计图表／期间切换、普通 Steam 统计静默、全部图标队列；鼠标悬停和手柄选择回归。
- 工具栏回归：四个窗口宽度、全屏、滚动显露焦点、下拉菜单、鼠标／手柄来回切换。
- 480 游戏导航：主页输入派发 P95 9.13ms、帧 P95 30.78ms、最大 46.86ms，0 帧超过 50ms；网格输入 P95 10.45ms、帧 P95 16.07ms。该结果来自隔离数据和模拟输入，不替代实际手柄手感。
- 真实 `data` 的 287 文件 SHA256 与既有基线一致。真实 source-preview 和游戏仅只读检查；所有 Store 测试使用隔离目录。

真实游戏内弹窗仍需真实解锁后验证；本轮没有把已有的普通／Anime4K 弹窗测试等同于这三款游戏的成功游玩测试。源码与便携版不同，体验本轮改动需要运行／重启源码版。
