GameCloudSave V2.5.0 使用说明

一、选择下载文件

安装版：GameCloudSave-Setup-V2.5.0.exe
双击安装包，阅读说明、选择安装目录并点击安装。按当前 Windows 用户安装，无需另装 Python；默认目录为 %LOCALAPPDATA%\Programs\GameCloudSave。可建立桌面和开始菜单快捷方式。

便携版：GameCloudSave-V2.5.0-Portable.zip
先完整解压，再双击 GameCloudSave.exe。请保持 _internal、licenses 等目录与主程序在一起，不要在压缩包内直接运行。便携版不注册 Windows 卸载入口。

源码包：GameCloudSave-V2.5.0-Source.zip
用于查看源码、开发和自行构建；普通使用请选择上面的安装版或便携版。

二、首次使用

首次启动按照设置向导逐页填写。Playnite、AList/WebDAV、DeepSeek 都可跳过；之后可以在设置中补充。Playnite 游戏库被占用时，先退出 Playnite 再导入。AList 的 WebDAV 地址通常是 http://服务器:端口/dav/，不是网站首页地址；还需账号权限和可写目录。

从“导入游戏”选择 Playnite、游戏平台或本地目录，预览并勾选要导入的条目。导入时可选择“仅导入”或“导入并查询”。后一项会打开新游戏的资料补全预览，不会直接应用网络候选。

点击单个游戏卡片的齿轮，打开三个页面：
1. 存档与云端：本机存档路径、存档查找和云端连接。
2. 封面与横幅：在当前页搜索、预览并选择两类图片，也可导入本地图片、填写图片链接。
3. 游戏资料：分类、标签、系列、发行日期，支持手动修改和查询补缺。

左栏“资料补全”可以一次查询全库缺失的日期、分类、标签、封面和横幅，并可补充系列。选择本次查询的内容，等待预览，核对名称、来源和图片，再点击“应用所选补全”。仅填缺失内容；已有资料、人工编辑以及预览后新增的内容保留。查询可以停止，当前网络请求结束后收尾。“仅显示缺失项”不将空白系列算作缺失；未匹配的游戏可在同页修改关键词搜索、选择图片或手动填写资料，加入预览后再应用。

首轮未查到的游戏会追加二次查询，尝试来源名称、别名和安装目录名称。Steam 还未发行的视觉小说可使用 VNDB 已有日期，标注 VNDB 来源。重名、续作编号或版本不明确时保留缺失，避免补错。DeepSeek 可辅助缺失分类、标签和名称识别，不会猜测日期；外部服务暂不可用时可稍后重试。

三、备份与恢复

在“查找存档”或“批量确认”中核对实际存档目录，再保存本地备份或上传云端。未运行过的游戏可能还没有存档。恢复前核对游戏、目录、设备和版本，重要进度请另保留备份。

自动监听默认每 5 秒在后台检查游戏进程，每次游戏结束后执行一次备份，游戏运行期间不持续压缩或上传。开启云端自动上传后，先保存本地再上传；失败可重试。默认每款游戏保留最近 5 份本机自动备份，可在设置调整；手动备份不限制，云端版本保留。存档记录时间跟随电脑系统时区，中国时区显示北京时间。

主窗口关闭后可能仍在托盘运行，完整退出请从托盘菜单选择“退出”。

四、手柄

当前源码版：左摇杆或方向键移动。侧栏选中即显示，切换范围后向右进入内容；从当前内容临时进入侧栏再向右时恢复原位置。上/下按实际布局移动，View（Menu 左侧）跳到搜索，再按一次返回原游戏或侧栏。焦点统一使用主题强调色。

当前源码新增“游戏设置 → 成就”：本地游戏可匹配 Steam 公开中文成就或导入定义，选择游戏生成的 JSON／INI 成就记录，保存独立监听与弹窗方案。通过本程序启动游戏后，首次导入不刷屏，新解锁在普通窗口／无边框和 Anime4K 放大时弹出，不抢焦点。没有可读成就记录的游戏无法自动判定，部分独占全屏需改无边框。LB／RB 切页，方向键／A 操作，Menu 保存、B 返回；详见 docs/本地成就与游戏内弹窗.md。此功能尚未进入现有发行包。

搜索处按 A 打开参考图布局的应用内键盘：A 输入／选词、X 删除、Y 空格、LB 清空、RB 中英切换、按下右摇杆切换大小写、Menu 提交、B 先退出拼音组合再返回。中文使用本机 Windows 输入法；搜索支持名称、完整拼音及首字母。

主页与内页的“筛选”位于平台、来源旁，可组合选择系列、标签、发行年份，标签多选匹配任一项。应用前可看结果数，工具栏可清除全部条件。默认布局的“随机游戏”从当前筛选范围抽取，先预览，A 启动、Y 换一款、Menu 游戏设置、B 返回，一轮内不重复。

四种布局中，A 启动，X 收藏，Menu 打开游戏选项（含画质增强），Y 打开存档记录。存档页支持本地备份、上传、本机／云端版本选择与恢复；画质页可用手柄选预设、改参数和保存。路径、资料、导入等未适配的复杂编辑仍使用鼠标，不支持的方向和 A 不会误触，B 可以返回。

从顶部“个性化”选择原版、书柜、影院或星图。书柜可选封面/书脊、木材和日光；影院有分类胶片和已有媒体；星图支持鼠标拖动、滚轮或右摇杆上下缩放。分组可选类别、系列、标签等，骰子按当前范围随机选游戏。个性化中可关闭动效。工具栏或 F11 切换全屏，B 返回和关闭设置保持全屏偏好。

启动游戏会播放完整过渡，再等待游戏窗口稳定可见后交接；超时可继续等待或返回，不会重复启动。窗口检测不等同于检测真实渲染的第一帧。

五、更新与数据位置

更新前退出主程序及托盘。安装版重新运行安装包并选择原安装目录即可升级；安装目录必须是专用空目录或已有 GameCloudSave 安装目录。不要把安装包指向便携版的 workspace 或其他混有文件的目录。

安装版数据：%LOCALAPPDATA%\GameCloudSave\data
下载的独立便携版数据：GameCloudSave.exe 同目录的 data
本工程原有启动新版.bat 数据：workspace\data

安装版和便携版的数据位置独立，安装不会自动搬移现有便携库。需要沿用便携库时，先退出两版并备份 data，再在同一电脑上手动复制完整 data 到安装版数据位置；不要覆盖已在使用的目标库。跨电脑请重新核对本机游戏/存档路径，密码和 API Key 需重新配置。

更新便携版时保留现有 data，覆盖程序文件和 _internal 等运行目录即可。发布包不包含你的游戏库、配置、Key、密码或备份。不要把个人 data 作为发行包上传。

六、卸载

安装版：Windows 设置 → 应用 → 已安装的应用 → GameCloudSave → 卸载；也可运行安装目录的 Uninstall.exe。卸载前退出托盘程序。卸载移除安装文件和快捷方式，保留用户数据与本地备份。

便携版：退出后移除程序文件即可；要保留数据，请先保留或另行备份 data。独立便携包中的 Uninstall.exe 用于安装版，不是便携版的卸载入口。
