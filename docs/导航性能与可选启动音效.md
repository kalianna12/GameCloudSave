# 导航性能与可选游戏启动音效

2026-10-21，用户要求快速手柄导航、右摇杆倾斜更跟手，提供音效开关、音量和多组选择；进一步明确较长的声音用于启动游戏。

## 改动

- 弹窗查找缓存当前窗口的候选项，在对应对象树新增/移除时失效。跳过其他工具窗口，避免每次方向输入扫描隐藏映射页的大量键帽与提示框；保留动态弹窗和模态拦截。
- 只有选中的有效卡片订阅右摇杆坐标，使用 `QPointF` 及独立开关属性，避免反复构造列表和读取含文件检查的整份设置。24ms 短插值衔接输入采样，滚动期间选中卡片继续倾斜，失焦、关闭动效或关闭倾斜时归零。
- 首页左右选择不再触发纵向布局/滚动；横向书架和普通网格按当前目标计算可见范围，仅目的地变化时启动滚动，75ms 完成，避免重复按键不断重启旧动画。
- 个性化提供即时音效总开关、0–100% 音量、九组音效选择或自动跟随布局。新增绒感、木纹、涟漪；原有轻触/轻柔/清亮、翻书/放映机/星光均可单独选择。
- 游戏启动声音单独选择：启程 1.4 秒、开场 1.7 秒、星际 1.8 秒，支持自动与关闭、独立试听。只在一次启动展示开始时播放一次，声音时长不参与游戏提交和就绪判断；取消不截断其他导航尾音。
- 音量直接作用于本程序的原生混音轨，当前尾音也随之调整，不修改系统或其他软件音量。静音/失焦停止本程序音轨。停止后保留 PCM 至队列确认清空，依据 [Microsoft FlushSourceBuffers 文档](https://learn.microsoft.com/en-us/windows/win32/api/xaudio2/nf-xaudio2-ixaudio2sourcevoice-flushsourcebuffers) 处理异步清空。
- 音效设置通过独立通知更新，180ms 合并并在既有串行线程落盘，不切全局 busy、不重建页面、不重置手柄。兼容 QML 传入的整数形式浮点值，保留其他设置，退出前提交待保存内容。
- 工具窗口的下拉列表优先处理手柄输入；滑块左右调节、上下离开，保留响应式数值绑定，A 试听。九组和三组启动音继续使用现有 CC0 作者素材，未加入运行依赖；清单现有 57 组事件 / 60 个 PCM 文件。

## 验证与范围

240 游戏隔离库、1920×1080 逻辑窗口，90 次右摇杆采样与 36 次快速方向分发：

| 指标 | 修改前 | 修改后一次测量 |
| --- | ---: | ---: |
| 摇杆引起卡片坐标更新 | 1980（22×90） | 90 |
| 方向输入期间完整弹窗树扫描 | 36 | 1 |
| 单次方向分发中位数 | 6.46ms | 1.06ms |
| 单次方向分发 P95 | 8.40ms | 1.91ms |

测量针对 Qt/Python 分发耗时，不代表端到端输入或显卡帧率保证。测试使用模拟手柄命令、真实 Qt 窗口和静音的真实音频设备；实际手柄手感及音色喜好仍需用户体验。

- 单元：`test_navigation_audio.py` 7 项、`test_audio_settings.py` 3 项、`test_input_logic_v3.py` 6 项，覆盖来源/淡入淡出/峰值、长短声音时限、原生缓冲、音轨取消隔离、实际主音轨音量、配置兼容及输入规则。
- 新增界面：`test_navigation_latency_ui.py` 检查订阅扇出和扫描次数；`test_audio_settings_ui.py` 检查即时静音/音量、手柄列表/滑块、九组路由、阻塞磁盘任务时继续操作、保存合并、动态模态弹窗、启动一次/取消且不延长提交。
- 既有相关回归：首页当前横坐标、工具栏多宽度导航、四布局音效、350ms GUI/GIL 阻塞下原生播放连续性、沉浸控制、书柜/影院/星图和游戏启动流程。
- 书柜测试改为选取有游戏数据且启用的真实书本实例，排除 Repeater 原型；保留鼠标抬书、书脊空白不触发等断言。额外尝试的历史 `test_navigation_v234.py` 依赖旧 winsound、推荐栏目出现前的行号及旧工具栏/A 菜单语义，不作为本轮通过项；当前规则由上述专门回归覆盖。
- 检查 600px 个性化音效设置截图。真实 `data` 共 287 文件 SHA256 与既有基线一致。

本轮只修改和测试 `workspace` 源码，不打包、不同步便携版、不上传发行包。
