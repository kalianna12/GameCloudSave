# 手柄模型比例与结构修复

2026-10-21，仅修改并测试 workspace 源码。

用户提供的三张实拍图作为轮廓、主体长宽比和正面按键位置参考，使用 SVG 外壳与同坐标系的 QML 交互按键实现。肩键、扳机为方便编辑向上展开，保留明显空隙，属于展开示意；表面渐变、层次和摇杆帽表达立体结构，不是可旋转的三维模型。

## 模型调整

- Xbox：重绘握柄和底部桥位，按实拍位置缩放并上移十字盘、右摇杆。加入黑色凹面分面十字盘、彩色字母黑色按钮、白色摇杆安装座和圆形功能键。底座、点击范围均在主壳内。
- DualSense：白色双翼覆盖深色中框，重画触摸板、灯带、扬声器和中间功能结构；左右摇杆和方向键匹配新外壳。L1/R1 与机壳、L2/R2 互不重叠。
- Joy-Con：彩色正面与深色内侧滑轨分层，补立体侧缘和安装座；校正 ABXY 的完整字母布局、左右摇杆、方向键、加减键。右侧按键全部在红色面板内，不依赖滑轨来遮盖越界。ZL/ZR 与 L/R 独立展开。
- 两种映射方向保持相同模型大小；标准按键仍复用原有 16 个交互对象，不因切换模型销毁重建。摇杆帽对角线运动归一化并限制偏移，避免重推时越过底座。

## 验证

`tests/test_mapping_model_geometry_ui.py`：通过。直接读取实际 SVG 的主体路径生成掩膜，密集检查正面按键矩形、安装座圆周是否在对应外壳内；Joy-Con 分别用左右彩色面板校验。检查后侧按键及阴影附近空隙、全部命中矩形互不重叠、摇杆八向极限行程。三种模型、两种尺寸、两个映射方向，共 192 次真实 Qt 窗口点击与 12 张完整模型截图。人工核对完整模型和小尺寸反向布局，未发现壳体越界、肩键重合或方向选择行遮挡。

完整模型截图位于 `test-data/model-review/`，例如 `xbox.png`、`ps.png`、`joycon.png`，以及 `*-reverse-small.png`。

相关界面回归均通过：

- `tests/test_input_mapping_ui.py`：模型切换、双向拖放、绑定录入、配置保存、轻重推预设、自定义组合、滚轮到摇杆和小窗口滚动。
- `tests/test_mapping_capture_ui.py`：三模型/两尺寸/双方向等大，键盘、鼠标、滚轮、手柄录入不误操作界面，取消和失焦恢复。
- `tests/test_mapping_performance_ui.py`：按键对象保持稳定；本机首次打开约 123.5ms，模型切换绘制约 4.5–9.9ms，缓存重开约 50.2ms，采集约 228Hz，预览约 125Hz，预览样本延迟 P95 约 3.6ms。数值为本机隔离测试结果。

所有测试使用临时 Store 或隔离测试目录，没有开启映射输出、安装驱动或操作真实游戏。真实 `data` 下 287 个文件的 SHA256 与 `build/release-2.5.0/data-after.json` 基线完全一致。没有重建、同步或发布便携版、安装包；重启 `workspace/启动源码版.bat` 可体验本轮修改。
