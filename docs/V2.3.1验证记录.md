# V2.3.1 验证记录

本轮为本地维护版本。程序输出固定在 `dist/GameCloudSave`；历史版本使用 Git 标签回溯，不保留多套运行程序。单实例按当前 Windows 用户和数据目录识别，重复启动唤回原窗口，避免同一游戏库多进程写入。

已停止 4 个旧版进程，删除 15 个旧打包目录、15 个对应构建目录、3 个旧安装器及根目录的两份旧 CLI/GUI 程序。桌面保留一个更新后的入口，当前只有一份新版主程序在运行。便携数据、原版 Windows 用户数据和历史 Git 标签保留。

查找页保留游戏选择、目录结果、评分、查找设置及进度。备份与上传在批量页、存档记录中操作。后台任务期间可以搜索、切换游戏、浏览结果和停止查找；会修改存档或配置的操作须等当前任务结束。批量任务的停止信号传入内部查找，已创建的备份保留。

向导内提供 Playnite 连接测试、DeepSeek API Key 设置与测试、DAV 登录与文件夹浏览。保存完整 DAV 设置时检查目录读写权限，临时检测文件随即删除。Playnite 客户端锁住数据库时提示关闭客户端；不强制结束 Playnite。

52 款隔离游戏的慢网络界面回归通过：搜索、切换、进度、取消、批量滚动位置、单实例唤回均已检查。实际 DeepSeek 查找《The Last of Us Part II Remastered》耗时 4.11 秒，返回 7 个候选，含目录比较评分；界面事件最大间隔 125 毫秒。只查找，没有修改或上传真实存档。

实际 AList 目录读取 0.36 秒，DeepSeek 模型连接测试 0.22 秒。Playnite 正在占用库；使用已复制的数据库验证同一导出程序，读出 51 款游戏。真实库仍需退出 Playnite 后再测试。

回归范围包括备份恢复、SQLite、中文路径、DPAPI、离线上传保留、云端路径、导入重复检查、平台归属、目录证据与评分、多个存档槽、标签与系列、向导、批量操作、监听、主题及图标对齐。打包程序验证首次启动、重复启动与本地备份恢复。安装器验证快捷方式、独立用户数据、源代码与许可证、卸载及保留用户文件。

最终安装器实测通过，安装版界面启动 1.90 秒；本机现有 52 款游戏的便携版启动 2.13 秒。4K 隔离压力测试使用 520 款游戏、20 个区块，滚动帧间隔中位数 15.12 毫秒、95 分位 36.42 毫秒。压力测试期间同时构建安装器，不能据此承诺所有电脑达到同样帧率。

不能直接宣称已经完成商业发行认证：当前 Windows 二进制没有代码签名，尚未覆盖不同 Windows 版本、不同显卡与真实多设备的长期连续运行。当前仓库没有配置 GitHub remote；本轮不会上传发行包。大版本发布前需确定公开仓库，补充签名及干净 Windows 环境测试。

日志限制在数据目录的 `logs` 下，最多三份、每份约 512 KB；不记录请求正文、API Key 或密码。配置与游戏库数据不进入 Git、源代码包或安装包。卸载不删除用户数据。

Codex 日志中存在 WebSocket 关闭与 HTTPS 流断开。已备份用户配置，新增使用同一 OpenAI 登录的 HTTPS provider，保持原模型和推理设置；本机 CLI 验证配置可加载。新设置对新建会话生效，网络及服务端故障仍可能造成重连。参考 [OpenAI 配置文档](https://developers.openai.com/codex/config-reference/) 与 [官方 provider 实现](https://github.com/openai/codex/blob/main/codex-rs/model-provider-info/src/lib.rs)。
