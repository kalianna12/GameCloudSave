# V1.6 并行存档查找

## 查找方式

每个游戏同时启动本地目录搜索、Steam 官方资料查询和 DeepSeek 参数识别。各路独立返回，结果逐步显示；网络或模型失败时保留本地结果。批量匹配默认同时查两个游戏，可设置为 1–3 个；网络和模型请求各限流两个。

本地搜索覆盖 Local、Roaming、LocalLow、重定向 Documents、Saved Games 和安装目录。索引扫描三层目录，支持“开发商 / 游戏 / Release”结构，不再要求开发商出现在固定名单中。比较中文名、英文名、安装文件夹名及别名，开发商目录提供额外证据。

目录索引有数量、深度与时间预算，复用 30 秒，手动匹配时刷新。跳过缓存、运行库、Unity 分析目录以及恢复前的临时备份，避免把它们当成存档候选。候选文件检查覆盖两层子目录；父子候选只有在属于同一组存档槽时归并，避免将 Demo 和 Release 混成一个备份。

Steam 从其商店接口提供标题、开发商和发行商，缓存一天。Playnite 链接含 Steam AppID 时直接查询；中文查询不明确时，可用 DeepSeek 识别的英文名再查一次。联网数据并非存档目录的最终证明。

DeepSeek 返回英文名、别名、开发商、发行商、引擎及允许根目录下的相对路径。程序提供少量相关目录名辅助识别；建议目录必须存在、不能越过允许根目录。身份参数缓存按游戏与模型区分。

多个候选无法区分时，可以将最多八个候选的相对目录和文件名交给 DeepSeek 比较。个人绝对路径和存档内容不发送。模型只能返回提供的候选 ID，不能创建新路径。只在本地存在存档证据时综合评分，本地占 90%，模型占 10%；缺少文件证据不会因为模型打高分而自动配置。

评分是规则与模型的比较分数，不是统计意义上的成功概率。多候选、共享目录或文件证据不足时仍需确认。

## Rubinite

Steam 官方页面：https://store.steampowered.com/app/1845250/Rubinite/

实际返回开发商 Cup Dog Games、GameWorks Ventures。本地最终选择：

```text
%USERPROFILE%/AppData/LocalLow/Cup Dog Games/Rubinite/Release
```

识别到该游戏的 GameData.json、Flags.json 带 ENC1 加密头；本地结合多个槽位和配对文件识别存档，无需解密。仍整体保存所有槽位。

本机隔离元数据缓存、真实联网和真实目录只读测试：首次 1.67 秒，本地候选首次显示 1.28 秒；缓存命中 0.28 秒，本地候选 0.12 秒。两次均选中 Release，评分 97/100。没有执行真实游戏备份、上传或恢复。

## 操作与验证

“查找存档 / 匹配设置”可开关联网查询、DeepSeek 目录辅助比较，调整并行游戏数。点击“保存查找设置”，或直接点击匹配按钮应用当前选项。完整结果显示开发商、各路完成情况、错误、评分依据及网络来源。

新增十二项查找测试覆盖未知开发商、模糊匹配、加密存档、运行库排除、索引缓存/预算、取消、三路并行和提前返回、联网失败回退、官方资料解析、无效模型 ID、模型不能替代本地证据及目录数据范围。多槽、备份工作流和界面回归继续通过。

```powershell
.\.venv\Scripts\python.exe tests\test_matching_engine.py
.\.venv\Scripts\python.exe tests\live_matching_engine.py  # 使用已保存 DeepSeek Key 和 Steam 网络，只读查找 Rubinite
```

双击上级“启动新版.bat”运行 V1.6。旧版 EXE 与 Git 标签保留。
