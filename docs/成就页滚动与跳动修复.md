# 成就页滚动与跳动修复

2026-10-24，针对用户反馈的游戏栏自行移动、垂直滑块无法拖动，仅修改 workspace 源码。

## 复现与原因

使用 64 款游戏、每游戏 220 项成就的隔离数据进行实际 QML 鼠标测试。旧代码在后台更新图标数后，将游戏列表整个数组重新作为 model 赋值，ListView 被重建，滚动位置从 337 回到列表顶部 -30。拖动期间更新也会使释放后的视口回跳。右侧成就滚动条无法保持 pressed 状态，实际拖动距离为 0。

成就列表另有每次换 model 后按选中项调用 positionViewAtIndex 的逻辑，会与鼠标自由浏览争夺位置。最近解锁、统计列表也共用整数组替换的做法。

## 修复

- 新增按稳定 ID 更新的 AchievementRecords 模型，复用项目已有的增量 ListModel 方案。只有新增、删除、次序改变才调整结构；图标数、状态、进度等只更新对应角色，常规更新按当前顺序线性处理。
- 游戏、成就、最近解锁、统计游戏列表均改为稳定模型。最近解锁增加 achievement_id，以游戏与成就内部编号区分同名成就。
- 后台更新不再强制滚到选中项；用户明确选择、手柄导航或打开详情时才定位。手动浏览到其他位置时保持所选游戏，不自动切换。
- 统一滚动条，显式开启交互，提供 12px 命中区域、最小 28px 滑块和更高输入层级。游戏、成就、外层设置、统计、最近解锁、详情说明和来源页均使用相同交互方式。

## 验证

`tests/test_achievement_scrolling.py`：

- 64 款游戏、220 项成就，图标与进度持续变化时，游戏／成就视口漂移均为 0。
- 实际 QTest 鼠标按下、分段移动、释放，游戏／成就／设置／统计／最近解锁共 10 次向上向下拖动均保持抓取，刷新后漂移为 0。
- 额外核对 900×650 与 1920×1080 的游戏、成就滑块拖动。
- 成就滚轮可移动内层列表，外层设置区漂移为 0；没有 QML 类型、绑定或递归布局错误。

原 `test_achievement_design.py` 与 `test_achievement_library.py` 回归通过，包括筛选、详情、键盘／模拟手柄、真实一秒计时器下的 Steam 封面计数、四布局。30 项解析／来源单元通过。真实 data 的 287 文件哈希不变。全部进度与鼠标操作使用隔离数据，未修改真实游戏库、设置、存档；未重启用户当前应用、未打包或同步便携版。
