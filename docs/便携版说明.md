# GameCloudSave

双击 `启动新版.bat`，或桌面的 **GameCloudSave Portable** 图标。重复打开会回到原窗口。关闭窗口后保留在托盘；需要退出时，从托盘菜单选择“退出”。

首次设置在同一个向导中完成。Playnite、DeepSeek、AList / WebDAV 都可跳过；之后从“设置”重新打开向导。Playnite 正在占用游戏库时，先退出 Playnite，再测试连接或导入。

导入游戏后，在“查找存档”查找目录，再到“批量确认”选择目录与游戏。确认后可保存本地备份或上传云端。云端按游戏名、原存档目录分级；从游戏的存档记录查看版本、添加备注或恢复。

配置、封面与备份保存在 `workspace/data`；原版数据仍保留在 Windows 用户的 GameCloudSave 数据目录。更新和卸载不删除游戏或存档。

当前程序固定在 `workspace/dist/GameCloudSave/GameCloudSave.exe`，不保留多套旧程序。安装版位于 `workspace/dist/installers`。开发说明与开源许可见 [workspace/README.md](../README.md)、[MIT 许可](../LICENSE)。
