# 游戏库视觉与动效改版

2026-10-16，源码版迭代；不构建或同步发行文件。

## 实施前设计

方向：游戏收藏柜。封面负责识别和视觉吸引，主界面负责找游戏、启动和备份，详细资料保留在游戏设置中。用户的主题强调色继续用于选中与主要操作。

- 色彩基底沿用碳灰主题 `#181a1c`、侧栏 `#202326`、操作表面 `#282c30`、文字 `#f3f5f7`、次级文字 `#a9b4bf`；强调色沿用用户设置（默认 `#80c942`）。其他内置/自定义主题使用同样的层级关系，不写死深色表面。
- 字体沿用 Windows 中文可读的 Microsoft YaHei UI；页面标题 28、分区标题 20、卡片标题 13、操作文字 12。减少粗重边框，以位置、留白、字体区分层次。
- 布局：侧栏固定导航 → 页面标题/搜索/导入 → 紧凑筛选 → 封面网格或横排书架。卡片结构为“封面 / 游戏名 / 启动与快捷操作”，去掉平台、安装来源、发行日期常驻行及其预留空间。

```text
导航       全部游戏  [数量]       [搜索]  [监听]  [导入游戏]
           [已安装] [平台] [来源]             [排序] [外观]
           ┌────────┐ ┌────────┐ ┌────────┐
           │  封面  │ │  封面  │ │  封面  │
           └────────┘ └────────┘ └────────┘
            游戏名     游戏名     游戏名
            启动  ⚙ ☁ ×
```

审阅：不引入与游戏浏览无关的仪表盘、数字统计或装饰文案。原有绿色属于用户指定主题，保留；通过封面占比、紧凑操作带、安静的筛选器和侧栏选中标记改善视觉，避免依赖换色制造“新界面”。

## 动效原则

固定鼠标检测平面，封面单独旋转；持续移动时直接跟随坐标更新，停止后保持对应角度。鼠标离开、滚动、窗口失焦、关闭动效、复用成另一款游戏时归零。手柄选中播放一次扫光和短暂抬卡，之后回正，快速跨卡时旧卡立即清理。空闲时不循环动画或使用逐帧计时器。

参考：[Microsoft 布局与间距](https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics)、[Qt HoverHandler](https://doc.qt.io/qt-6/qml-qtquick-hoverhandler.html)、[Qt SmoothedAnimation](https://doc.qt.io/qt-6/qml-qtquick-smoothedanimation.html)。

## 交付实现

- 网格去掉平台/已安装/可备份与发行日期行，横排去掉平台/Playnite/已安装行；资料仍保留，发行日期排序和资料编辑正常使用。卡片底部从 144 缩至 90 像素，保留两行游戏名与一行启动/设置/云端/移除操作，启动带文字。
- 首页最近游戏使用横向封面预览，名称和主要操作叠入图内，避免额外的大块操作底座。分区移除重复说明；侧栏以主题色短线和浅色底标记当前位置，降低非当前导航项的权重。
- 页面数量改为标题旁的小标记；筛选器与次要操作减轻边框，导入保持明确主操作。统一输入、按钮、图标按钮圆角与边框强度，保留强调色焦点提示。网格按可用宽度重新分列，900 像素窗口和默认封面大小下显示三列，减少固定封面宽度产生的右侧空白。
- 鼠标倾斜上限由 6° 调整至水平 18°、垂直约 14°；宽幅首页预览上限 7°，避免大图边缘变形过多。连续位置更新直接驱动角度，不等待鼠标停止或弹簧追赶。光带与封面一起变换，输入区域保持固定。
- 切换输入模式时清理旧坐标，并要求新指针移动才再次激活。手柄抬卡在约 320 毫秒内归正；旧卡离开选中立即清零，扫光只播放一次。滚动、失焦、关闭动效及复用身份改变均停止动效并归零。
- 修复网格/首页在位置没有变化时仍启动滚动动画的问题，防止同一行左右移动也无谓暂停整页封面反馈；横排滚动动画也计入动效暂停条件。

## 验证与性能边界

`test_cover_motion.py` 使用实际 QML 验证：连续移动时逐帧采样角度、快速手柄左右移动与进入侧栏、鼠标/手柄切换、隐藏窗口、关闭动效、滚动暂停与身份复用、收藏点击和封面设置点击。移动轨迹在尚未停止时已达到约 ±14°；静止选中后 300 毫秒观察期重绘 0 帧。报告在 `test-data/cover-motion/report.json`。

`test_library_refresh.py` 使用隔离数据和只读复制的已有封面，验证 900/1440/1920 像素窗口、深浅主题、操作区未越出卡片、资料仍可读取，以及首页启动按钮不会同时打开设置或重复启动。图片上方的图标使用独立的对比色和透明底，保证浅色主题同样可辨认。截图在 `test-data/library-refresh/`：`home-dark.png`、`home-light.png`、`grid-desktop.png`、`grid-compact.png`、`grid-wide.png`、`grid-light.png`。

导航网格、V2.3.4/V2.3.3 输入、首页筛选/滚动保持、设置/长路径、资料补全、向导和批量确认等既有 UI 回归逐个通过。没有启动真实游戏或修改真实配置、存档，没有实测游戏 FPS。

进程监听机制本轮未改动：默认每 5 秒检查一次，运行中不执行自动压缩上传。之前本机 30 次短时测量的单次采样中位数约 1.74 毫秒，按 5 秒间隔估算约占一个 CPU 核心的 0.063%；这不是整机性能或 FPS 保证。封面使用普通场景图变换和一次光带，不增加逐帧进程扫描、轮询鼠标的计时器或常驻循环动画；窗口失焦时停用封面效果。

全部验证为源码版。便携版、安装包与 GitHub 发行包未改动；重启源码进程后生效。
