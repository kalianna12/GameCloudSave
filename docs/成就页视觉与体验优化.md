# 成就页视觉与体验优化

## 设计方案

沿用当前全局主题，成就页以游戏收藏与独立徽章为视觉中心。默认基色参考：背景 #181a1c、侧栏 #202326、表面 #282c30、主文字 #f3f5f7、次文字 #a9b4bf、完成纪念金 #d9be82；实际颜色服从 Theme，操作强调色服从用户设置。金色用于全成就，稀有度颜色只表达全球解锁率等级。

字体使用应用既有 Microsoft YaHei UI，标题 22–26px、游戏标题 18–21px、成就标题 14px、说明 12px。左对齐，减少重复状态段落。层次来自封面、徽标、留白和细分隔，不铺满相同大卡片。

布局：顶部轻量导航；左侧可搜索游戏收藏列表，右侧当前游戏封面与完成度、筛选和可浏览成就列表；底部紧凑图表。窄窗自动调整过滤工具排布，匹配与诊断保持展开式。完整说明通过成就详情层展示。

方案复核：保留用户 Playnite 参考中的双栏与底部图表，沿用应用主题。将主要视觉变化集中在选中游戏与真实徽章，避免泛用仪表盘式大数字和装饰性渐变。图像取自游戏已有缓存，不生成或伪造成就图标。

## 验证与结果

2026-10-24 已完成源码实现：

- 游戏列表移除默认批量复选框与重复缓存说明，使用封面、状态与进度作为主要信息；批量模式显示已选数量、全选和取消选择。
- 当前游戏增加封面、名称、完成度圆环与记录连接状态。补齐详情数据缺少 has_record 导致连接状态误显示的问题。设置展开后才显示匹配与诊断信息。
- 成就行使用独立徽标、状态侧线、稀有度与解锁日期；点击或手柄 A／键盘 Enter 打开完整说明。长说明支持滚动，隐藏成就名称和图标保持保护，稀有度未知排在已知值后面。
- B／Esc 关闭详情并恢复原成就焦点；游戏列表右移直接进入成就，左移返回游戏列表。实时解锁更新后保持当前选中的成就 ID。成就详情弹窗实现正式 controllerInput 入口，手柄分发不会被无适配弹窗截断。
- 搜索与筛选响应式排布，增加结果数量、重置筛选、不同空结果提示。Ctrl+F 定位游戏搜索。最近解锁和统计条目可跳回游戏，使用真实 game_id，避免同名误跳。
- 普通高度窗口优先浏览列表，大窗口默认显示底部图表，可通过“图表”开关展开／收起。修复统计图表无限扩展挤掉游戏列表、圆环描边被裁切、柱状图悬停索引偏移；浅色主题稀有度使用更深颜色。动画服从全局开关，复用虚拟列表委托。

通过 `tests/test_achievement_design.py`：900×650、1280×880、1440×1000，深紫／浅色／琥珀主题；窄窗统计列表可见，完整详情和长文滚动、真实分发入口下的模拟手柄命令、Qt 键盘 Enter／Esc／Ctrl+F、隐藏信息保护、批量选择清空、最近与统计跳转、游戏设置内嵌详情及实时更新焦点保持。测试未产生 QML 类型、绑定循环或布局递归警告。

原成就管理／四布局徽标／Steam 静默实时计数回归、30 项单元测试、真实一秒计时器隔离回归通过。测试全部使用临时进度，真实资料与独立图标仅从已有缓存读取，截图完成数是演示数据，不能视为实际游戏解锁。真实 data 287 文件哈希保持不变。未打包、未同步便携版或发布。
