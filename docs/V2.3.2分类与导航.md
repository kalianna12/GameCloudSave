# V2.3.2 分类与导航

分类页把未分类游戏放在前面并默认选中。“全选未分类”不会选中已有分类、标签或系列的游戏。“选择全部…”或单独选中已分类游戏时提示确认，默认按钮为取消。保存时再次检查保护条件，未经确认的批次整批拒绝，避免半批生效。

DeepSeek 的标签只能使用当前游戏库已有词库；整个库没有标签时使用内置基础词库。同义词、英文名称与中文名称合并到库内现有写法，不自由生成新标签。主分类也限定在内置与用户现有分类中。结果仅为预览，应用后才写入游戏库。模型、游戏名或词库变化会使缓存失效；相同输入复用缓存，降低漂移和重复请求。

仍可手动编辑标签并加入新的用词；新词在应用后进入词库。重新分类已有游戏时会合并旧标签，并按当前词库统一同义词。没有合适标签的结果保持空标签，不强行关联。仅有一款游戏的自动系列不展示，现有系列默认保留。

最近游玩的左侧横幅显示当前选择，右侧封面、箭头、拖动与横向滚动可以切换。刷新游戏资料时按游戏 ID 保留选择。子页面“返回”恢复上个页面、搜索和滚动位置；手柄 B 同样返回。

手柄使用 Windows 自带 XInput：方向键/左摇杆选择，A 查看或确认，B 返回/取消，X 收藏，Y 打开存档记录，Menu 启动游戏，LB/RB 切换控件焦点。按钮有边沿防抖，方向键有按住重复及摇杆死区。弹窗打开时阻止库内快捷启动；返回只关闭当前弹窗。后台停轮询，没有连接时每 1.5 秒检查一次。支持原生 Xbox/XInput 手柄；纯 DirectInput 手柄不在本轮支持范围。

焦点边框和选择反馈使用主题强调色。横幅切换、滚动与高亮只在操作时播放短动效；关闭“界面动效”后立即切换。“个性化”可关闭手柄导航。

验证包含固定词库、同义词去重、已有分类默认跳过、缓存重复结果相同、未确认的整批拒绝、动态横幅与选择保留、返回位置、手柄控制实际 Qt 按钮、弹窗保护、手柄恢复前台时忽略按住的 A 键及关闭轮询。现有游戏库、匹配、向导与图标对齐回归通过。

实际 DeepSeek 对隔离的 Rubinite、Celeste、Fate/stay night 三项预览约 0.99 秒；标签全部属于现有词库，再次请求结果完全相同。真实用户游戏库没有修改。当前电脑未连接 XInput 手柄，已测试状态映射与界面响应，实物手感仍待验证。XInput 接口与死区参考 [Microsoft 文档](https://learn.microsoft.com/en-us/windows/win32/xinput/getting-started-with-xinput)。

本轮只更新固定便携目录与最新安装器，不上传 GitHub 发行包；个人设置、游戏文件和存档保留。
