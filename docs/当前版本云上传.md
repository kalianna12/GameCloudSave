# 当前版本云上传

本机已安装 rclone，并发现名为 alist 的 remote；尚未验证连接或写入权限。

在便携版目录打开 PowerShell：

```powershell
rclone listremotes
rclone lsd alist:
```

第二条命令只列目录。根据结果选择真实目录；若 GameCloudSave 放在某个网盘下，例如 网盘/GameCloudSave，path 应填写这个完整相对路径。

已有 remote 不可用时运行 `rclone config`，新增或修改 alist：Storage 选 webdav，URL 填 AList 的 https://你的地址/dav/，vendor 选 other，用户名密码使用 AList 用户。用户需有目标目录上传权限，挂载存储也需支持写入。

参考：https://rclone.org/webdav/ 和 https://alistgo.com/guide/webdav

## GUI

启动 GUI，选择已有游戏，点击“配云端”：remote 填 alist（不带冒号），path 填目标相对路径，例如 网盘/GameCloudSave。点击“手动存档”，填写备注。程序先生成本地 ZIP，再上传；历史中 uploaded=yes 表示成功，失败保留本地 ZIP。

## CLI

```powershell
.\gamecloud.exe config-cloud --remote alist --path "网盘/GameCloudSave"
.\gamecloud.exe set-cloud "游戏中文名" --remote alist --path "网盘/GameCloudSave"
.\gamecloud.exe save "游戏中文名" --note "测试云存档"
.\gamecloud.exe history "游戏中文名"
```

config-cloud 只影响以后添加的游戏；已有游戏需要 set-cloud 或在 GUI 中配置。
目标结构：alist:<path>/<游戏名经过 slugify 处理>/<快照文件名>.zip。
此处路径为示例，需要换成真实挂载目录。本轮未上传任何真实存档。
