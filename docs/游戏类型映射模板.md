# 游戏类型映射模板

2026-10-20，源码迭代。八组均为手柄到键鼠的离线起始方案，不是针对某个游戏的官方完整配置。

入口：主页左侧“手柄映射”→“游戏模板”。左侧选择类型，右侧预览两个摇杆和全部 16 个标准输入的按键与用途，长表可滚动。可以“创建并编辑”单组，或“添加全部 8 组”；添加后自动保存并出现在主页映射选择中，不会自动启用映射。

重复添加会跳过已有模板；改名、改键后的配置保留。已有模板按钮显示“打开配置”，当前方案的未保存修改也不会因重新打开同一模板而丢失。批量添加保持当前草稿和正在使用的方案，不重新启动映射。每组仍能复制成多份；“恢复默认配置”恢复该类型的模板，保留自定义名称、手柄模型和编号。

替代输入分开配置。例如 VN 的 A 为 Enter、RT 为鼠标左键，RPG 的 A 为 Z、RT 为 Enter，不把二者做成同时按下的组合，避免一次触发两次确认。肩键、扳机、十字键、摇杆按下与菜单键都已设置；没有加入系统键、Share 或厂商背键的原生采集。

平台跳跃、俯视动作和战棋不会在重推时自动加 Shift，防止误触冲刺、抓取或修饰选择；FPS、生存和 RPG Maker 使用轻推走、重推 Shift 跑/冲刺，仍可在两组方向设置中修改。

模板的用途标签表示建议用途；游戏键位不同，应在游戏中改键或在映射编辑器录入实际按键。已原生支持手柄的游戏可能同时收到实体输入和模拟键鼠，模板不会屏蔽原始设备。

## 参考与取舍

- [Ren’Py 官方按键表](https://www.renpy.org/doc/html/keymap.html)：Enter / Space / 左键推进，Ctrl 按住快进、Tab 切换快进，Esc / 右键菜单，滚轮上回看；默认自动键为空。因此模板标明 A 自动需要游戏支持，存读档保留菜单加鼠标方案，没有把 S、F5、F9 冒充通用存读档键。
- [RPG Maker MZ 官方操作说明](https://rpgmakerofficial.com/product/MZ_help-en/01_06.html)：移动为方向键，Z / Enter / Space 确定，X / Esc 取消和菜单，Shift 冲刺，Page Up / Page Down 翻页。W 默认用于下一页，RPG 模板因此不采用 WASD 移动。
- 其他类型为本工程建议的可改键起点，不宣称适配每个游戏的默认键位；尤其 J / K 攻击、Space 结束回合、C 制作等，应按游戏核对。FPS 的鼠标模拟需要调节游戏内灵敏度，不代表原生手柄辅助瞄准。

## 验证与范围

10 项模板单元检查覆盖完整绑定、独立副本、八向/重推与回中、鼠标和滚轮输出、单组/批量持久化、重复添加保留修改、容量和写入失败的原子性、运行中批量导入及按类型恢复默认。

`tests/test_mapping_templates_ui.py` 通过真实鼠标点击遍历八组预览，验证 1040×700 浅色布局及滚动到表格最后一行、单组和批量添加、主页可用、草稿保留及手柄导航 B 只关闭模板弹窗。截图位于 `test-data/input-mapping/templates-*.png`。原有映射单元、组件单元、拖放/录入/滚轮/保存界面与性能回归继续通过。

测试只使用临时隔离数据，没有向真实游戏注入输入；真实游戏库和存档、便携版及安装包不变。本轮没有逐一实测八类真实游戏的键位。
