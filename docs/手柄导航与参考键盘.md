# 手柄导航、参考键盘与启动器交接（源码版）

2026-10-23。仅更新 `workspace` 源码，使用临时游戏库测试；未同步便携版、安装包或 GitHub 发行包。

## 参考键盘

按用户提供的键盘参考图重排：上方大输入框，四排各十个数字／字母键；右列为删除、跨两行的完成和取消；底部是两格大小写、六格长空格、两格清空。采用方格、细边框与主题色选中描边，沿用软件主题。按实际格位导航，大键保留进入时的行／列，横向不绕到另一排；900 × 650 与 1440 × 900 均检查无越界。

| 手柄按键 | 键盘中的功能 |
| --- | --- |
| 方向键／左摇杆 | 移动选中键 |
| A | 输入／确认候选词 |
| X | 删除 |
| Y | 空格／提交当前候选词 |
| LB | 清空 |
| RB | 中英文输入切换 |
| 按下右摇杆 R3 | 大小写（按住不会反复切换） |
| Menu | 提交搜索；有拼音候选时先提交候选词 |
| B | 先退出拼音组合，再退出键盘 |
| View／Back（Menu 左侧） | 关闭键盘并返回进入工具栏之前的位置 |

中文输入调用本机 Windows 输入法；虚拟按键仅在本进程搜索输入框获得前台焦点时送入系统。不向游戏发送按键，不使用全局输入钩子，不把库内词条列表当成中文输入法。排除了语言编号为中文、实际键盘仍为 US 的布局；兼容输入法自行显示候选窗、仅向 Qt 提交最终文字的情况。关闭键盘／退出程序恢复本线程原输入布局和模式。本机搜狗输入法实测 `nihao` → `你好`，包括 Menu 提交尚未确认的候选词；其他输入法的候选翻页方式仍取决于系统输入法。

搜索同时支持中文名称、别名、完整拼音和首字母，例如 `沙耶`、`shayezhige`、`syzg`。使用 pypinyin 0.55.0（MIT），有界缓存避免导航和刷新时反复转换；Qt 预编辑期间不触发筛选。拼音首字母按库内名称生成，多音字的不同读法不保证全部命中。

## 导航与流畅度

主页左移进入侧栏后，右移恢复刚才的栏目、游戏和滚动位置；实际切换侧栏分类才重置。View 把焦点移到搜索，可继续调整工具栏；再次按下返回之前的游戏或侧栏。B 先处理当前弹层、输入／工具栏，再返回内容和浏览历史。

主首页外层改用精确高度的 Flickable 与按视口激活的轻量栏目 Loader，消除可变高 ListView 估计 originY 后产生的位移。内层卡片／图片保持异步；选中卡片优先，隐藏栏目卸载。横栏关闭 Qt 自动跟随高亮，由一套边界计算控制滚动；横向位置使用相对 originX 的逻辑坐标，离屏重建、收藏刷新后恢复。空的推荐加载栏不接受方向选择。垂直滚动限制到实际最后一栏，恢复焦点时把选中项带回视口。

收藏立即更新显示，80ms 合并快速点击后通过现有串行持久化队列保存，不再使整个程序进入忙碌状态。标签别名预建索引，缓存标准标签集合，避免每次生成栏目重复遍历和规范化整套别名；保持原有标签语义。

隔离 480 款带图游戏、60 次快速上下输入，D3D11：输入处理 P95 约 9.4ms，帧间隔 P95 约 27.5ms、最大约 51.7ms；同步滚动跳写 0 次。网格输入 P95 约 11.2ms；实际后台采样模拟长按 1 秒产生 9 次向下指令，松开后位置稳定。160 款库的单次收藏 GUI 调用约 36–59ms，磁盘队列延迟时 UI 仍立即更新。以上是本机隔离测试，非所有机器／冷加载场景零掉帧承诺。

## 存档与画质设置

Y 打开存档记录，方向选择本地备份、备份并上传、重试和刷新；LB／RB 切换本机／云端，向下进入版本列表，A 打开恢复预览并可继续选择槽位／账号和确认恢复，B 逐层返回。恢复确认明确调用原有恢复流程，保留恢复前备份；测试用临时库与替身验证调用，不恢复真实游戏存档。

Menu 游戏选项新增“画质增强”直达。画质页可用手柄移动、修改算法／参数、选择完整预设，Menu 保存：Galgame 全屏、动漫精细、3D 游戏全屏、通用清晰、像素 2 倍窗口及关闭增强。

0–100% 是**锐化强度**，不是分辨率或缩放百分比。全屏目标为游戏所在显示器的物理分辨率，界面显示当前屏幕尺寸，例如 3840 × 2160；保持比例时允许黑边。窗口模式分别按原始游戏画面宽高乘倍数，例如 1280 × 720 的 2 倍为 2560 × 1440，以显示器可容纳范围为限。切换预设不会擅自更改游戏内部渲染分辨率。

## 独立启动器

启动观察阶段辨认标题、窗口类和可见的原生 Start／开始游戏等按钮。识别到本游戏相关启动器后，解除游戏库置顶、收起启动遮罩，交接到该窗口，继续在后台等待实际游戏；实际窗口稳定后才进入原有画质增强流程。用户切到其他无关程序时尊重其前台选择，过期或取消的回调不重新抢焦点。

临时原生按钮启动器与后续渲染窗口实测通过：交接时库窗口已解除置顶，启动器阶段不应用增强；实际游戏窗口就绪才调用增强一次。没有运行《沙耶之歌》或改其设置，真实游戏仍需用户体验。平台／自绘启动器如果没有可辨识标题、按钮或进程关联，可能仍需手动切窗或指定监听 EXE。
