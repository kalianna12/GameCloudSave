# V2.0 导入、云端版本与后台运行

## 导入游戏

游戏库右上角“导入游戏”提供三个入口：

| 入口 | 读取内容 | 选择方式 |
|---|---|---|
| Playnite | games.db 中的游戏名、封面、平台、安装位置、启动操作 | 勾选 Steam、Epic、Ubisoft、本地/其他；重复导入保留本机存档设置 |
| 游戏平台 | Steam appmanifest 与 libraryfolders、Epic 安装清单、Ubisoft 安装注册表 | 先读取，再勾选游戏导入 |
| 扫描文件夹 | 所选目录下的 EXE/BAT/CMD，默认 6 层，可设 1–10 层 | 预览路径与评分；每款游戏只选一个启动文件 |

平台直读仅包含本机已安装游戏，不读取账号密码，也不代表账号拥有的全部游戏。未安装游戏通过 Playnite 导入。Playnite 正在独占数据库时会提示关闭后再导入，不会关闭客户端或修改数据库。

平台标签使用 Playnite 官方插件 ID；游戏卡片和扫描预览显示平台标识，首页可按平台筛选。Steam 本机缓存中有对应封面时可读取；其他封面保留已有 Playnite 封面，或在游戏设置手动选择。

扫描不执行任何文件。规则过滤常见安装器、卸载器、运行库、崩溃报告程序与游戏平台客户端；最多检查 20,000 文件、显示 500 候选。达到限制时提示缩小范围。单游戏内部 Binaries/Win64 等目录保留游戏根目录。

DeepSeek 辅助识别为可选操作，需要 API Key。只发送游戏文件夹名、启动文件名和相对路径，每批最多 50 个候选、并行 2 批。返回候选 ID 和名称必须通过校验；规则占评分 80%，模型占 20%。模型失败保留规则扫描结果。评分不是“正确启动文件的概率”，仍需确认。

BAT/CMD 可直接启动；额外参数写在批处理里。在游戏设置中填写“监听进程 EXE”，才能监听批处理启动的实际游戏进程。游戏平台启动也可配置此项。

## 存档版本和多设备

从游戏卡片云朵按钮打开“存档记录”：本机版本按时间排列，可添加备注并选择恢复。“云端 / 其他设备”页点击刷新读取版本，选择“下载并恢复”后会先校验、再备份当前存档、最后恢复。

每台电脑分别设置游戏路径、备份位置和 DAV 凭据。使用同一个云端根目录、相同游戏名称，即可查看共同云端版本；存档目录和电脑分组变化也在游戏目录内查找。导入方式导致 ID 不同时，仅允许具有匹配游戏名与 SHA-256 记录的新版本跨来源导入；名称不同或重复名称的游戏可能需要先统一条目。

新上传的 ZIP 附带 `.zip.json`，保存游戏身份、UTC 时间、备注、来源电脑和 SHA-256。下载校验失败不会覆盖本机。修改已上传版本的备注会更新附属记录，不重写 ZIP。旧版本没有附属记录时保留原有身份检查与 ZIP 校验，来源和备注可能不完整。

当前为手动选择版本的多设备备份和恢复，不自动合并游戏进度，不自动用云端版本覆盖另一台电脑。两个设备各自的进度都保留为独立版本；上传时间使用 UTC，机器时钟仍需准确。老版本时间缺少时区时存在排序限制。

百度网盘目前继续通过 AList/DAV 使用。独立连接入口说明开放平台授权要求并提供官方入口；没有 Client ID/Client Secret 和用户授权时，独立连接尚未启用。

## 性能和后台运行

- 启动不检查整库封面缓存；导入和更换封面时处理，现有图片异步加载。
- 首页有“自动监听”开关；关闭时停止监听计时器。
- 监听间隔可设置 5–60 秒，默认 10 秒。先在后台比较运行状态，只有启动/退出事件发生时备份，不在空闲检查时禁用界面。
- 优先按 EXE 完整路径识别进程，避免不同游戏都叫 Game.exe 时串档；无法读取进程路径时仅对唯一名称回退匹配。
- 默认关闭主窗口进入托盘；托盘可打开游戏库、开启/暂停监听、退出。系统设置可改为直接退出，托盘不可用时直接退出。
- 云端刷新、导入和扫描均由用户触发，不在空闲时反复联网或扫描磁盘。首次启动速度仍受硬盘、杀毒软件及 Qt 初始化影响，不能保证所有电脑都一秒内启动。

本机独立程序三次测量，从创建进程到界面初始化完成为 0.840、0.765、0.789 秒；这些是缓存后的初始化耗时，封面异步加载与首帧呈现另受显卡和窗口状态影响。

## 验证范围

本机直读观察到 20 款 Steam 已安装游戏；D:\GAMES 扫描观察到 11 个候选，DeepSeek 对 11 个候选返回评分。Epic/Ubisoft 没有可用本机安装样本，已通过安装清单/注册表隔离测试。实际 Playnite 数据库被客户端占用，平台过滤通过只读导出模拟测试，实际重新导入需关闭 Playnite 后操作。

8 项来源与同步测试覆盖分级扫描、BAT 启动、去重、平台识别/选择、两设备版本/备注/恢复和损坏拒绝。真实 DAV 使用生成的测试存档完成上传、附属记录、另一配置下载恢复与备注更新，测试目录已清理，没有修改真实游戏存档。
