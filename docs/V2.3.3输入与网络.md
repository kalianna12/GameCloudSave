首页只高亮当前行的当前磁贴。最近游玩大图是预览，不重复绘制焦点框；切换行保留 QML 焦点绑定，复用磁贴时旧行不会继续高亮。控件获得焦点时，磁贴退出焦点显示，鼠标悬停使用次要颜色。

手柄上下滚动与网格翻行使用 190 毫秒缓出过渡，快速连按从当前位置继续。横向滚动保持平滑，鼠标滚轮仍使用较短的 110 毫秒过渡。“个性化 → 界面动效”关闭动画；“导航提示音”关闭提示音。提示音为本地 45 毫秒 PCM 音频，异步播放，不引入多媒体播放器与常驻音频线程。

收到手柄命令后隐藏鼠标，暂停悬停响应。静止鼠标或合成鼠标事件不会夺回输入；实际移动、点击或滚轮恢复鼠标。切到其他程序、断开或关闭手柄导航时恢复鼠标。只使用事件过滤器，无额外鼠标轮询。

本机网络排查：127.0.0.1:10090 为现有 mihomo HTTP/SOCKS 代理。直连和显式 HTTP 代理都能获得 Codex、OpenAI、DeepSeek 服务的 HTTP 响应；未授权探测返回 401 只证明连通，不代表认证成功或长连接稳定。日志中确有 HTTPS 响应流中断，不能仅凭短请求认定根因已解决。

本机已设置用户级 HTTP_PROXY/HTTPS_PROXY 为该 HTTP 代理，NO_PROXY 保留原值并增加 localhost、127.0.0.1、::1 和当前 AList IP，让本地 DAV 不经代理。Codex 保留 HTTPS 传输，流重试上限从默认 5 次调整到 8 次。需完全退出再启动 Codex/VS Code 才能继承新环境；本轮未强制退出工作会话。官方配置说明见 [OpenAI Docs](https://learn.chatgpt.com/docs/config-file/config-reference)。

修改前的 Codex 配置和代理环境值分别备份在本机 `.codex/config.toml.before-network-20261010.bak` 与 `.codex/network-env-before-20261010.json`。这些本机文件不进入源码包。其他电脑无需使用本机代理地址。
