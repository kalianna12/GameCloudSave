# GameCloudSave V2.7.0

这版集中处理游戏启动交接、成就运行开销、图片搜索和发行体积，同时整合之前的源码界面与手柄改进。

- **彻底移除游戏内成就弹窗**：删除弹窗窗口、队列、预览、窗口跟踪及启动预热；保留实时成就统计、独立图标、封面徽标和成就管理页。记录变化驱动更新，总开关关闭即停止监听。
- **游戏启动**：独立启动器优先交到前台，游戏库不再长期置顶。Playnite 可读的唯一文件动作直接启动，并保留参数、工作目录；兼容数字形式的动作类型。需要脚本或模拟器的动作保留原方式。
- **安装状态**：核验本机游戏文件，删除游戏目录后标记未安装，保留资料、成就与存档；切回软件时后台复查。存档存在不再作为已安装依据。
- **页内图片搜索**：Google、Bing、IGN、SteamGridDB、GOG、Epic 与原有 Steam/VNDB/API 来源统一展示候选、预览、应用，不打开外部浏览器。动态页面按需使用系统 Edge 无窗口采集；来源受限时在当前页提示。
- **云存储**：原生 WebDAV/AList 和 GitHub 仓库可选，浏览、快照上传、版本下载及恢复沿用同一流程；Token 使用 DPAPI 保存。GitHub 单份快照限 90 MiB。
- **查找存档**：读取 Steam 本机云存档规则，缺失时参考 SteamDB 公开路径；“一键应用可靠结果”批量处理有真实进度证据、无歧义且无冲突的目录，保留已经确认的路径。
- **成就界面**：收紧列表层级、完善进度展示、调整滚动条边缘与命中位置，保留列表位置、键盘/手柄导航及图表。
- **轻量化**：移除随包 Chromium、rclone 和未使用的 Qt 模块；保留影院媒体、音效和手柄映射依赖。映射编辑器首次打开异步创建、后续缓存，空库测试工作集约减少 48 MiB。安装器约 104 MiB、便携包约 96 MiB，较 V2.6.0 缩小约 60% / 62%。

提供安装器、便携包、源码、完整报告及 SHA-256 校验清单。安装版原目录升级；便携版更新前退出托盘并保留 `data`。真实游戏库、凭据和存档不进入发行包。

验证包括单元回归、实际 QML 操作、临时启动器窗口、冻结程序四布局、安装/启动/卸载流程和隔离 GitHub 云端往返。详细数据、限制及复现入口见本版 `GameCloudSave-V2.7.0-Report.md`，或仓库中的[完整报告](https://github.com/kalianna12/GameCloudSave/blob/v2.7.0/docs/V2.7.0完整优化报告.md)。
