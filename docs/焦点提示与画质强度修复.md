# 焦点提示与画质强度修复

2026-10-24，源码版迭代。

## 焦点高亮

主窗口及另外 11 个应用窗口统一接入 `ControlFocus.qml`。原生开关、复选框、页签、滑条、数值框和输入控件获得主题色焦点框；编辑数值框内部文本时，仍突出整个数值框。已有明确焦点框的自定义控件沿用自身样式，避免双框。

焦点框只随焦点事件更新，随控件一起滚动和裁剪，不轮询、不接受鼠标操作。窗口失去激活时隐藏。游戏设置使用 LB/RB 切页后，将焦点明确移到新页签。

## 顶部进入封面的提示音

顶部最后一行向下进入内容时，选中游戏的索引可能没有变化，因此原有选中变化通知没有发出移动音。现在明确通知这次焦点区域移动，保留原有的音效去重机制。四种布局及书柜／影院／星图自身分组工具栏均覆盖，没有修改音频素材或增加滤波。

## 增强强度

新增低 35%、中 70%、高 100% 三个直接选择按钮，支持手柄导航。Anime4K 低档使用轻量算法，中／高档使用精细算法；其他支持锐化的算法保持当前算法。像素整数缩放不显示锐化强度。

快捷方案中的 Galgame 全屏改为精细 70%，动漫精细改为精细 100%；3D 游戏全屏和通用清晰分别提高到 65% 和 60%。强度只调整算法及锐化，不代表输出分辨率。单独调整强度不会修改显示方式、缩放倍数、帧率或捕获方式；原有手动数值及其他游戏方案不会被自动覆盖。保存后按游戏记忆。
