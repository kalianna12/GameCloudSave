发布日期：2026-10-21（中国时间）。整合 V2.5.0 之后的双向手柄映射、推荐、多存档跨设备查找与恢复改进，并优化首页重复更新和发布依赖完整性。

更新前退出主程序和托盘。安装版选择原安装目录；便携版保留自己的 `data`，覆盖程序及 `_internal`。安装版数据在 `%LOCALAPPDATA%\GameCloudSave\data`，便携数据在自身 `data`；两者不自动搬移数据。跨电脑使用时，Windows 加密的密码和 API Key 需要重新填写。

## 双向手柄映射

- 主页左侧“手柄映射”入口。上方完整键盘与鼠标，左下 Xbox / DualSense / Joy-Con 三种模型，右下实时预览与按键历史，详细参数位于下方。
- 手柄到键鼠：任意标准按键绑定键盘、鼠标或最多 12 键组合；支持直接录入、点击选键和拖动绑定。左摇杆可用 WASD 或方向键，轻推、重推独立设置八方向及附加组合；右摇杆可控制鼠标，灵敏度、死区、曲线与平滑可调，也可映射滚轮。
- 键鼠到虚拟 Xbox：输入组合映射按钮、扳机或摇杆方向，支持鼠标视角和滚轮到摇杆、可调保持时间与回中。
- 组合显示为可点击键帽：点键名替换，点 × 仅删除一键，保留其他成员；输入组合和输出组合分别编辑，整组清空仍可用。录入时 Enter、Esc、Delete、方向键、滚轮与手柄全部参与录入，取消用鼠标按钮，不误触界面或退出全屏。
- 八组完整模板：VN/Galgame、平台跳跃、俯视动作、FPS/TPS、战棋、模拟经营、生存沙盒和 RPG Maker，可预览后创建，保留个人修改。可保存多个配置，直接在游戏库主页选择方案或“无”。
- 三种模型参考实拍重画外壳、按键和材质，肩键/扳机展开便于编辑；正反向模型等大，拖动显示目标高亮与提示，长组合自动换行。
- 采集线程与界面发布分离，保留短按边沿，模型预加载并复用按键对象。使用菜单定位鼠标方式改善部分视觉小说中的光标重置干扰。

手柄到键鼠不需额外驱动。反向映射已随包带 vgamepad 与客户端 DLL，仍需 ViGEmBus 系统驱动；映射页可检测并按需下载校验、打开安装窗口，程序不自动重启电脑。映射每次启动默认关闭；`Ctrl + Alt + F12` 停止输出。切换至本程序时暂停输出，关闭映射页仍可继续已启用方案。

三模型按标准 XInput 物理位置工作；PS/Joy-Con 需先由系统或其他工具转换为 XInput，不代表原生陀螺仪、触摸板、SL/SR 支持。模板快捷键需按具体游戏调整。程序不会隐藏实体手柄；同时接收原生手柄和模拟鼠标的游戏可能仍需关闭原生手柄或单独设置设备隔离。未在用户真实游戏中验证所有映射兼容性。

## 首页、导航与性能

- 首页推荐 Steam 国区新发布、促销、热门及 Xbox 港区精选，后台并发获取资源和缓存图片；点击打开官方商品页。设置可关闭全部推荐或单个来源。
- 单栏刷新不重置整页、其他栏目、选中项和滚动位置。推荐连续返回时合并更新，未变化的卡片不重复写入模型；只改变一张图片或价格时仅更新对应卡片。
- 主界面游戏卡片与最近游戏预览显示退出备份、上传、成功或失败状态，不再只在右下角提示。
- 全屏进出、最小化和桌面返回保持正确状态，减少反复切换引发闪屏；关闭工具页不误恢复为窗口模式。
- 四种布局的工具栏按实际位置导航，首页上下方向按当前卡片横向位置选择；A 启动、Menu 打开游戏菜单、Y 存档、X 收藏、B 返回。右摇杆可控制选中卡片倾斜，星图中仍用于缩放。
- 原创导航短音效、风格与音量设置，预加载避免按键时读盘。动态背景、封面和摇杆预览继续尊重关闭动效、隐藏/失焦等状态。

## 多存档、跨设备和联网查找

- 多槽恢复预览可选择账号与单个槽，跨设备先明确账号映射；恢复前保留副本，失败时回滚，避免把另一账号目录直接覆盖到当前设备。
- 云端通过游戏平台 ID 和目录索引发现同一游戏，不只依赖本机标题；保留本地备份与云端上传状态区分。
- DeepSeek 辅助查找增加网页初查和二次深查，结合来源证据、本地文件验证及规则生成候选。包含卡赞的 `BBQ` 等与显示名不同的目录规则。
- 改进 Steam AppID、目录短名、续作编号、配置/空文件排除，补全结果筛选和查找状态筛选。联网受服务、凭据和网络影响，不保证所有游戏自动查到；采用候选前仍需确认实际存档。

跨设备恢复不能绕过游戏自身账号、加密或平台限制；不自动识别游戏内部每个存档槽的专有格式。此次验证使用隔离生成存档，没有恢复或上传个人存档。
