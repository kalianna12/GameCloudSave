# GameCloudSave V2.7.0 完整优化报告

日期：2026-10-26。适用系统：Windows。本次按用户明确要求构建并发行安装版、便携版和源码包；后续日常修复仍只修改 workspace 源码并使用隔离数据测试。

## 一、交付范围

这版彻底移除游戏内成就弹窗，保留静默成就统计；精简运行依赖和安装载荷；完善启动器窗口交接、Playnite 直接启动、真实安装检测、GitHub 云存储、Steam 云存档路径及批量确认，并统一所有图片搜索为当前页面内的候选列表。此前源码中的四种布局、搜索键盘、筛选、音效选择、画质增强、手柄焦点与存档操作一并纳入发行。

发行入口：https://github.com/kalianna12/GameCloudSave/releases/tag/v2.7.0 。源码回溯以 `v2.7.0` 标签为准。

## 二、成就运行开销与退出

删除 `app/achievement_overlay.py`，移除成就弹窗窗口、通知队列、预览入口、游戏窗口绑定、启动前预热与置顶处理。无论普通窗口、全屏还是 Anime4K 放大，都不再由本程序创建成就通知窗口。Steam 客户端自己的提示不受本程序控制。

静默进度更新改用 `QFileSystemWatcher` 监听记录文件与所在目录，80 ms 合并短时间变化；只有存在已配置监听路径时才启用 10 秒兜底检查。不再为成就反复枚举游戏进程或寻找窗口。原子替换、文件晚到、半写入和后台任务忙碌都有重试或合并机制。

总开关关闭后停止事件监听、兜底定时器和待处理检查，晚到结果不恢复监听；完整退出先关闭成就模块，再清理其他任务。右上角关闭到托盘仍属于程序运行，需从托盘选择“退出”结束程序。

成就定义、每项独立图标、来源、稀有度、封面完成圈、最近解锁及饼图/柱图/趋势图保留。匹配定义和读取进度分别处理：只有定义列表不能判断本地游戏解锁；必须有支持格式的实际记录。不会伪造成就或把数值 `1` 一律当成已解锁。

## 三、启动与安装状态

### 独立启动器

启动过渡期间释放游戏库的临时置顶；检测到所属启动器或游戏窗口后恢复并激活目标。前台线程临时附着在操作结束后解除；不发送模拟按键、不长期锁定前台。用户已经主动切到无关程序时保留现有前台保护。启动器继续创建游戏子进程后，原有画质增强与光标交接流程保留。

### Playnite

兼容 Playnite 文件动作类型 `File`、数字 `0`，识别 EXE/BAT/CMD，展开安装目录变量、相对路径和工作目录，保留参数。唯一可确定的文件动作直接执行，不要求启动 Playnite。此前已导入的游戏在后台尝试只读更新；启动时仍可补读旧配置。人工修改的路径和参数优先保留。

依赖 Playnite 前后脚本、模拟器或存在多个无法明确选择的启动动作时保留 Playnite 启动方式，避免跳过必要准备步骤。平台游戏仍可能需要其平台客户端完成授权。

安装判断使用实际启动文件；只有目录信息时核对非空游戏目录。Playnite 的 `IsInstalled` 和存档路径都不作为决定依据。启动文件不存在时提示重新选择或安装，并保留资料、成就、备份及存档。程序启动与切回前台时后台复查，15 秒内合并重复激活检查，不递归扫描磁盘；删除后重新放回文件可恢复状态。外部磁盘暂不可用时也可能显示未安装，重新连接后切回软件复查。

## 四、全部图片搜索留在当前页面

封面、横幅与手动资料补全使用同一结果组件。Steam Store、VNDB 和 API 来源保持原有流程；Google、Bing、IGN、SteamGridDB、GOG、Epic 改为后台采集图片 URL、缩略图和可获得的尺寸，在页面内选择、预览后应用。来源或图片类型改变时清理旧请求归属，晚到结果不会覆盖新搜索。

Google 优先读取原图和缩略图配对，正确处理宽高顺序；Bing 读取结果元数据。其他网页读取图片与嵌入数据，过滤图标、小图和重复地址。普通 HTTP 无法获得足够结果时，按需调用已安装的系统 Edge 无窗口采集，使用临时配置目录，采集完成/取消后清理自己创建的进程。程序不附带 Chromium，不打开外部浏览器窗口，平时不常驻浏览器。

实测关键词 `Ori and the Will of the Wisps`：Google 48 项、Bing 39 项、IGN 16 项、SteamGridDB 29 项、GOG 4 项；这只是当时的公开页面结果，数量和相关性由来源决定。Epic 在本次网络环境未返回可用结果，当前页显示失败提示，不会改为打开浏览器。验证码、登录和地域限制不绕过；没有系统 Edge 时仍可使用能直接返回数据的来源。

## 五、原生云存储与 GitHub

移除发行包中的 rclone，WebDAV/AList 改由程序直接进行 PROPFIND、MKCOL、PUT、GET、DELETE。保留现有云端目录结构、版本清单、备注、校验、跨设备下载和恢复流程，旧设置无需搬移云端快照。下载先写临时文件再替换；快照重名不同内容时拒绝覆盖。

GitHub 使用仓库 Contents API，设置 `owner/repo`、可选分支和仓库读写 Token，空分支使用默认分支。Token 用 Windows DPAPI 保存，不写入普通设置 JSON。上传以分块 Base64 流生成请求，避免同时保留多份完整存档副本；写入快照形成仓库提交。列表查询避免为读取 SHA 再下载整个归档。

GitHub 单份快照上限 90 MiB；特别大的目录列表、服务限流或权限不足会明确报错，较大备份建议使用 WebDAV。建议专用私有仓库；Git 历史会保留已提交的内容，删除当前文件不等于清除仓库历史。

真实联网测试在独立临时分支上传生成的测试文本，验证上传、列举、下载、一致内容复用、不同内容拒绝覆盖和删除，最后删除临时分支。未上传用户存档。WebDAV 使用本地 HTTP 测试服务验证协议操作，跨设备快照与恢复流程使用隔离数据验证；未在真实 AList 中恢复用户存档。

## 六、Steam 云路径与一键应用

优先从本机 Steam `appcache/appinfo.vdf` 读取对应 AppID 的 `ufs`，支持版本 39、40、41；使用映射文件和有界索引，避免反复解析整个库。映射 Documents、AppData、Saved Games 等 Windows 根目录，拒绝越界路径和无法识别的变量，账号通配展开有数量限制。

本机规则缺失时请求 SteamDB 公开 UFS 页面并缓存；站点拒绝访问时继续其他本地规则，不依赖其始终在线。规则仅作为路径线索，实际目录必须有可读进度证据，配置文件如 `settings.bin`、音频配置不会单独触发自动确认。可信 Steam 路径与真实进度证据不会再被辅助模型低分直接压下。

“一键应用可靠结果”按当前选择范围批量保存无歧义目录。已人工确认的路径保留；分数接近、多存档根冲突或多个游戏共享同一路径均留待“批量确认”，冲突双方都不抢先占用。应用路径本身不自动上传或恢复。未查过优先、排除已确认及全量重新查找保留。

只读查看本机 Ori 2 的 Steam 规则，得到 Local 下 `Ori and the Will of the Wisps`，模式含 `*.uberstate`、`*.txt`、`*.bindata`、`*.bin`，读取约 4 ms。规则中的设置文件与真正的进度文件仍需区分。

## 七、外观和使用体验

沿用既有主题，成就列表缩短重复文案，以独立图标、标题、说明、状态和进度构成明确层级。封面概要增加底部进度轨道，行背景去掉重复颜色动画。滚动条靠右对齐并预留外层间距，避免内外滚动条重叠；保留足够鼠标命中区、稳定列表 ID 与刷新位置。修复图表字体声明，避免绘图期间反复产生字体警告。页签、开关、滑条和按钮的手柄焦点继续使用主题强调色。

保留完整来源与许可证说明、凭据用途等有实际作用的提示，移除成就弹窗相关开关、重复声明和过时功能描述。云存储入口统一用“云端连接”，游戏设置中能够正确显示 GitHub 仓库。

## 八、体积、性能与验证

### 轻量化方法

排除 QtWebEngine、PDF、QtQuick3D、设计工具等未使用模块与插件，删除随包 rclone，只保留使用的 legacy 核心文件。保留 Qt Quick、SVG、Multimedia 以及手柄映射客户端，影院视频、音效输出设备切换和映射功能仍可使用。安装载荷由不压缩 ZIP 改为 Deflate，提供源码与组件许可证。

手柄映射编辑器取消未打开时的自动预加载，首次打开异步创建，后续重新打开复用缓存。同机空库、启动 16 秒后取样，工作集约从 415.1 MiB 降至 367.1 MiB，约少 48 MiB；本程序 CPU 约 0.39%（以单个逻辑核心为 100%），未创建子进程。此测量不含游戏、下载、图库纹理或大型成就库，不能当作所有实际库的内存上限。首次映射窗口绘制约 92 ms，编辑器完整就绪约 1.37 秒；再次打开首帧约 68 ms。

精简前本机主程序文件 686,661,159 字节（约 654.9 MiB），3,137 个文件，不含个人数据。精简后的主程序运行文件约 214.4 MiB，减少约 67%；含卸载器、源码和许可证的完整程序目录约 226.8 MiB、2,572 个文件。

| 发行文件 | V2.6.0 | V2.7.0 | 缩减 |
|---|---:|---:|---:|
| 安装器下载 | 259.4 MiB | 约 103.8 MiB | 约 60% |
| 便携 ZIP 下载 | 252.4 MiB | 约 95.5 MiB | 约 62% |

最终字节数以发行资产和 `SHA256SUMS.txt` 为准，表格使用四舍五入值；报告、源码及许可证均纳入最终载荷。压缩下载大小与解压体积分别统计。

## 九、数据与更新

测试使用 `test-data` 临时数据，不向真实游戏保存路径写入。真实 `data` 基线共 287 个文件，SHA-256 校验保持不变。发行包排除 `data`、`test-data`、机器凭据、缓存及 `.venv`；压缩包完整性与文件清单单独校验。

安装版更新前退出程序及托盘，选择原安装目录；便携版保留 `data`，完整替换程序运行文件。安装版数据位于 `%LOCALAPPDATA%/GameCloudSave/data`，独立便携版数据位于程序旁 `data`，两者不自动搬移。跨电脑重新配置本机游戏路径和加密凭据。卸载保留个人数据。

本次发布安装器、便携 ZIP、源码 ZIP、独立完整报告和 SHA-256 清单。没有额外建立多份长期便携程序目录；安装测试使用隔离临时目录。
