# V1.4 云端目录与管理

## 上传结构

上传改为使用 Playnite 的游戏名称，路径固定为：

```text
选定的云端根目录/
  ELDEN RING/
    EldenRing/
      时间戳备份.zip
  DJMAX RESPECT V/
    Saves/
      时间戳备份.zip
```

每次仍先创建本地 ZIP 备份，再上传。失败时本地文件保留。补传读取备份中的原始存档目录，因此改了当前电脑的存档路径也不会把旧备份分到错误目录。

中文游戏名保留。名称中的路径分隔符及 Windows 不允许的字符使用全角字符替代，例如 `Fate/stay night` 使用 `Fate／stay night`。重名游戏才添加短标识用于区分，正常游戏不再显示 UUID 文件夹。

在“云端存储 / 备份”选择游戏，可查看实际路径预览。可选“存档目录下按电脑分组”，增加电脑名称层；需要点击“保存设置”生效。连接、路径及传输选项仍按电脑独立保存。

## 云端管理

- 左侧分为备份、连接、传输三个页签。
- 文件列表支持名称筛选、文件夹筛选、隐藏文件、按名称 / 修改时间 / 大小排序、刷新、新建文件夹及下载文件。
- 下载保存到用户选择的位置，不自动恢复或替换游戏存档。
- “整理旧备份”：先进入旧文件夹，点击按钮，选择对应 Playnite 游戏。软件从 ZIP 元数据读取存档目录，复制到新层级，重新下载并校验 SHA-256；旧备份保持原位。
- 整理时不覆盖已有目标文件，已有文件必须通过完整性校验。复制进度记录在该电脑配置下的 `cloud-organize-report.json`，已校验的本机历史记录更新到新云端路径。
- 传输页可设置 1–3 次尝试、10–120 秒超时、自动备份后是否上传。自动备份需要先在系统设置开启游戏监听。

未选择文件时预览面板收起，文件列表获得更多空间。选中文本或图片可预览，其他文件显示信息。
