# 参考键盘、游戏库筛选与随机游戏

2026-10-23，源码迭代，回溯基线 `1087c7a`。仅修改 `workspace`，未重建便携版、安装包或发行包。

键盘按本次参考图重新绘制：透明外层，不再套整块圆角面板；整条灰色输入框，下方按一格左右的留白间距接连续方格键区。四排数字／字母，右侧删除、跨两行的完成／取消，底部两格大小写、六格空格、两格清除。X、Menu、B、R3 下压、Y、LB 直接画在对应按钮上；肩键与摇杆使用矢量外形，避免用文字方框替代。保留输入框内的 RB 中英切换、系统中文输入法、拼音候选提交和无鼠标手柄操作。背景取当前游戏图片并压暗；未选到游戏图片时保留暗色遮罩。

主页和内页在“全部平台／全部来源”旁增加统一“筛选”入口。系列、发行年份可单选，标签可多选；系列、年份、标签之间同时满足，多个标签匹配任一项。年份可选“未记录”。筛选窗口显示结果数，取消不应用草稿，支持清空条件与应用；工具栏显示已选条件数量和清除入口。筛选在本次运行的页面切换间保留，不写入用户配置。

主页各本地栏目使用同一组条件重新生成，内页和书柜／影院／星图也使用相同的筛选结果。筛选启用时不混入缺少对应库内资料的商店推荐；零结果显示空状态并可清除。若更改平台、来源或游戏资料后，已选条件暂时没有匹配值，仍在筛选窗口保留该值供查看／清除，不把实际条件错误显示成“全部”。原本只在系列页出现的单独系列下拉改由统一入口承担。

默认布局的筛选区补上“随机游戏”骰子，与既有其他布局的骰子样式一致；宽屏与筛选同排，窄屏按实际可用宽度换行，右侧布局／个性化／全屏仍贴页面右边缘。随机范围遵守当前页面、搜索、平台、来源、仅已安装和新增筛选条件。一轮抽完前不重复，多于一款时避免跨轮连续重复；先显示封面预览，不直接启动。预览中 A 启动、Y 换一款、Menu 游戏设置、B 返回，按钮直接带相应图标。

新增 `test_library_filters_random.py` 用临时 40 游戏库验证组合条件、草稿取消、未知年份、旧条件保留、主页／内页／四种布局一致性、随机不重复和显式启动确认、900–2560 宽工具栏边界、48 个标签下的焦点滚动，以及参考键盘格位、无间隙和大键跨行比例。没有启动真实游戏。
