# V2.3 游戏库主页

## 平台和导入来源

“全部游戏”包含已经导入本软件的所有条目，可来自 Playnite、游戏平台或本地扫描。Playnite 中尚未选中导入的条目不会自动进入本软件。平台与导入来源分别筛选。

| 条目来源 | 平台判据 | 导入来源 |
| --- | --- | --- |
| Playnite Steam 库插件导入的游戏 | Steam 插件 PluginId | Playnite |
| Playnite Epic / Ubisoft 库插件导入的游戏 | 对应插件 PluginId | Playnite |
| Playnite 手动添加的本地游戏 | 空 PluginId，归本地 | Playnite |
| Steam / Epic / Ubisoft 本机平台扫描 | 实际安装清单或客户端安装记录 | 游戏平台 |
| EXE / BAT / CMD 文件夹扫描 | 本地启动文件 | 本地扫描 |

未知 Playnite 库插件归“其他”。商店链接、封面、安装文件夹中包含 Steam 字样都不作为平台归属。`steam_appid` 仅用于确切的 Steam 库条目；封面和资料匹配 ID 保存为 `metadata_steam_appid`。中文或本地游戏使用 Steam Store 封面后仍可归本地。依据见 [Playnite Game.PluginId 官方文档](https://api.playnite.link/docs/api/Playnite.SDK.Models.Game.html#Playnite_SDK_Models_Game_PluginId)。

在“导入游戏 → Playnite 游戏库”点击“更新已导入信息”，只更新已经导入的条目的平台、游玩资料、类型、标签及背景图。保留本机存档路径、启动设置、收藏和人工分类。Playnite 锁住数据库时需关闭客户端再读取；启动软件不自动连接平台或请求 AI。

旧版本缺少平台字段的条目不能凭 Steam 链接修复。当前工作目录已依据以前保存的 Playnite 原始导出校正匹配 ID 的 51 款条目；新增手动条目已从错误的 Steam 归属改回本地。该导出是历史资料，新游戏或最近记录可通过上述更新按钮刷新。

## 首页

按顺序纵向浏览，横排可拖动或通过箭头翻页：

1. 最近游戏：第一款用宽幅背景展示，提供启动、设置和存档按钮。无游玩记录时显示已安装或收藏游戏。
2. 按类别浏览：主分类封面磁贴，点击进入该分类全部游戏。
3. 按系列浏览：采用同样的磁贴；只显示至少两款不同游戏的系列。
4. 根据最近游玩推荐：从本库匹配共同标签和类型，排除最近展示的游戏。这是本地计算，不在滚动时调用 DeepSeek。
5. 类型与风格横排：主分类及恐怖、恋爱、合作等风格，点击“查看全部”筛选。全部条目随时可从侧栏“全部游戏”打开。

主分类默认九个：视觉小说、角色扮演、动作冒险、射击竞技、策略模拟、解谜休闲、竞速体育、音乐节奏、其他。没有游戏的分类不显示，侧栏不铺满标签。允许人工创建自定义分类。

每款游戏只有一个主分类，可以有多个标签。原来的多个分类保留为标签；迁移前 `library.json`、`groups.json` 的副本位于 `data/migrations/v23`。迁移不改变游戏 ID、存档位置或已有备份。

“管理分类与系列”提供主分类下拉框、逗号分隔的标签、系列名。规则和 DeepSeek 都先给出预览，勾选后应用。模型结果统一系列名称，剔除只含一款游戏的系列。用户手动填写的系列信息可保留用于搜索，但不足两款时不会出现系列磁贴。

## 搜索与性能

搜索同时匹配名称、主分类、标签和系列，多个词取交集。例如 `恐怖 恋爱`、`#视觉小说`、`开放世界 RPG`。平台和导入来源筛选可组合。

首页和横排采用可回收的列表项，滚动只加载附近的磁贴。封面异步按显示大小解码，背景图限制解码尺寸；首页数据按游戏库变化缓存。收藏和资料更新保留列表位置，动效仅响应翻页、悬停和滚动，可在个性化中关闭。
