# 页内图片搜索与横幅选择

2026-10-16，源码迭代。测试使用隔离数据，不改写真实游戏库、配置及存档，没有更新便携版或安装包。

## 使用入口

- 卡片齿轮 → **封面与横幅**：选择“封面”或“横幅”，填写名称、选择来源并搜索。候选显示图片及横幅状态，点击“使用此封面／使用此横幅”保存更换。仍可使用图片链接或本地文件。
- 侧栏 **资料补全** → **手动搜索与补全**：可修改游戏名，在同页搜索、分别选择封面与横幅，也可匹配 Steam/VNDB 资料。选择图片后留在当前页，可继续操作；点击“返回补全预览”，最后“应用所选补全”才写入游戏库。
- 补全列表增加 **仅显示缺失项**。只缺系列名称的游戏不会被视为资料不完整。日期、分类、标签、封面及横幅继续参与缺失判断；已有补全建议尚未应用的游戏仍属于缺失。系列仍可以手动填写和补充。

## 图片来源

Steam 搜索结果在后台用最多四个详情线程补充资料与横幅地址，先显示候选、再逐条更新，见 [异步搜索与布局手柄导航](异步搜索与布局手柄导航.md)。候选标明“有横幅／无横幅／横幅查询失败”；封面与横幅页可查看同一游戏的两种图片。VNDB 使用封面和截图。横幅状态反映来源返回的地址，实际保存还会下载并校验图片。

Google 图片、Bing 图片、IGN、SteamGridDB、GOG 和 Epic 在当前页内加载。加载完成后尝试采集图片并显示为原生候选列表；也可点击“采集本页图片”。没有采集到合适图片时保留搜索页，可在页内点开图片、完成网站验证，再采集。网页来源只提供图片候选，不将网页图像推测成发行日期或标签；这些资料可在左侧填写。

本轮替代此前“打开浏览器，再粘贴地址”的流程。网页验证、登录限制和原站图片不可下载等情况仍受网站影响；失败会保留重试入口，不跳到外部浏览器，也不绕过网站验证。

候选按图片类型过滤已知尺寸；页面采集最多显示 48 张图片，拒绝本地或脚本 URL。网页视图仅在打开搜索时加载，关闭、切页或采集成功后释放；使用临时浏览配置，禁止网站下载直接落盘。下载与横幅校验在工作线程执行，图片预览异步加载。连续重搜更新关键词和请求标识，过期结果不能写入其他游戏的候选。

补全选择只更新预览，应用时再次检查已有数据，保留原资料。游戏设置中的“更换”是用户明确操作，可以替换当前图片。手动选择资料匹配时只加入日期、分类及标签等资料，不替换已选图片。

## 书柜与影院

骰子仍遵守筛选和分组范围。鼠标点击骰子后，抽中的书自动滚入可见区域并拿起，继续选择其他游戏时收回；同一游戏出现在多个标签层时只高亮当前层。关闭动效或窗口失活时遵守现有暂停规则。

影院把“正在请求下一张图”和“完全没有可显示横幅”分开。切换到有横幅的游戏时保留旧帧，下一帧就绪后过渡，右侧封面不再短暂露出；真正无横幅或当前图片加载失败时仍显示封面。

## 验证

- 35 项单元检查：来源横幅配对及失败状态、采集过滤/去重/上限、选择预览不写库、已有图片保护、资料匹配保留已选图片、横幅尺寸校验，以及原补全、日期与二次匹配回归。
- 8 组独立界面回归：页内图片搜索、布局与骰子、影院双缓冲、视频停止释放、资料补全、启动与全屏、导入、网格手柄导航。Qt 界面测试依次运行，使用隔离游戏和图片；启动回归只操作隔离测试子窗口。
- 页内搜索用本地 HTTP 图片页通过真实 Chromium 渲染、采集、重搜、封面/横幅筛选、下载保存和同页预览；检查选择按钮没有被正常大小的设置窗口裁掉。
- 真实 Google 页内查询 `Counter Strike 2 game cover`，采集到 8 张候选；此项验证查询和展示，没有替换真实库图片。未声称所有网站都已逐一完成在线采集。
- 界面截图复核位于本机 `test-data/image-search-review`，抽书截图位于 `test-data/experience-review/shelf-random-picked.png`；测试资料不进入 Git。
