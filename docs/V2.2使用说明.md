# GameCloudSave V2.2

## 启动和安装

已有便携版用户继续双击上级目录的 `启动新版.bat`，使用原来的 `workspace/data`。先从托盘退出旧版，再启动新版。

`dist/installers/GameCloudSave-Setup-V2.2.1.exe` 是独立安装包，不要求安装 Python 或管理员权限。默认装入当前用户的 `AppData/Local/Programs/GameCloudSave`，可创建桌面和开始菜单快捷方式。安装版个人数据存放在 `AppData/Local/GameCloudSave/data`，与便携版独立。卸载保留个人数据和存档备份。

首次启动按页设置 Playnite（可选）、本地备份、AList/DAV（可选）、DeepSeek（可选）、封面来源和后台选项。每页可跳过，最后核对预览。已使用的电脑也可在系统设置重新打开向导。各电脑分别设置安装路径、存档路径和凭据。

## 导入游戏

- **Playnite 游戏库**：只读读取现成游戏与封面，默认仅已安装；预览后导入所选。无平台选择，支持 Playnite 的手动条目。客户端占用数据库时需先关闭 Playnite。
- **游戏平台**：读取本机 Steam、Epic、Ubisoft 已安装条目；不是在线账号的全部购买记录。排除本软件与 Playnite 已有游戏。
- **本地文件夹**：扫描分级目录下 EXE/BAT/CMD，过滤安装器和常见工具。扫描不执行文件。相同安装目录的不同启动文件可二选一。名称、平台 ID、安装路径提供重复检查；规则不确定的结果或 DeepSeek 提示均需人工核对，不直接合并。

新条目排在前面，已确定重复项不可选，可能重复项导入前提示。Playnite 暂不可读时会使用本机上次读取的参考记录并提示；缓存可能漏掉刚加入的游戏，建议关闭 Playnite 后再次读取。

## 封面来源

| 来源 | 使用方式 |
| --- | --- |
| Steam Store | 软件内搜索、预览、下载，可按分数自动匹配 |
| VNDB | 软件内搜索视觉小说、预览、下载，不需要填写 Key |
| Google、Bing、IGN、SteamGridDB、GOG、Epic | 打开浏览器搜索，选好后粘贴图片直链或导入下载的图片 |
| 自定义 JSON 来源 | 设置 GET 搜索接口后软件内搜索、下载 |

DeepSeek 可辅助识别英文名，但不保证识别正确。自动封面匹配只采用分数较高且领先其他候选的结果，其余手动选择。IGDB 入口已移除。

实测 Steam Store 与 VNDB 搜索、下载成功；其他来源验证了搜索网址，Epic 自动探测出现 TLS 连接中断。网页打开依赖所在网络和网站规则，不能保证一直可访问。第三方封面版权归原作者。

自定义接口在“个性化”或设置向导中填写，例如 `https://example.com/search?q={query}`。软件将 `{query}` 替换为 URL 编码的游戏名，GET 返回以下 JSON：

```json
{"items":[{"id":"game-1","name":"Game name","image":"https://example.com/cover.jpg","page":"https://example.com/game-1"}]}
```

`page` 可省略。最多读取 30 项，响应限制 4 MB，图片限制 12 MB 和 8192×8192。接口只能提供数据，不执行代码。变更接口后不会复用上一个接口的搜索缓存。

## 游戏库管理

侧栏提供全部游戏、最近游玩、收藏、系列和自定义分类。封面上的星号切换收藏；成功请求启动或监听到启动后记入最近游玩。启动请求成功不等于游戏已成功运行。

“管理分类与系列”可以创建、重命名和删除分类，编辑每个游戏的分类与系列，或者生成规则/DeepSeek 建议，勾选所需条目后应用。分类用逗号分隔，同一游戏可属于多个分类。删除分类保留游戏和存档。

布局设置提供实时封面尺寸、每行数量、间隔；封面尺寸调整会切换为自动列数。“个性化”提供碳灰、浅色、午夜蓝、深紫，强调色、动效和托盘通知开关。SVG 图标按屏幕缩放绘制，封面按需解码，原图分辨率决定细节上限。

## 主题接口

导入数据格式见 `theme.example.json`，规范见 `theme.schema.json`。使用 `schemaVersion: 1` 和八个颜色字段（`#RRGGBB`）。缺省颜色继承碳灰主题。主题大小不超过 64 KB，文字与背景对比度需达到 4.5；不加载主题中的 QML、脚本或网络资源。

## 备份、恢复和后台

“批量确认”在一个页面展示每款游戏的候选目录，可全选、分别切换目录或手动选择。确认后备份使用已设置的目录，不重新请求 AI。多存档槽位应选择共同存档根目录。

V2.2.1 的存档候选评分默认采用 DeepSeek 75%、本地规则 25%，在查找页面“DeepSeek / API Key”内可将 DeepSeek 权重设为 50–95%。目录比较会降低配置、缓存等候选的评分，也会提高真实存档容器的排序。已保存的 AI 比较结果可直接重算，不重复请求；仅有一个候选时也会比较。目录或文件不存在时不会靠 AI 高分提升可信度；自动配置仍需本地存档证据，附带补丁和示例存档保持低分。请求失败时回退本地规则并提示。

每次备份先保存本地 ZIP，再尝试上传。云端使用 `所选根目录/游戏名称/存档目录名/快照.zip`，旁边 JSON 保存时间、来源电脑、校验值和备注。可选电脑分级目录。旧版目录整理先复制校验，保留原件。

游戏卡片云朵按钮打开按时间排列的存档记录，可写备注、恢复本机版本，或读取并下载其他设备的版本。不同电脑需各自设置真实本地存档路径；程序不会把旧电脑的绝对路径直接用于新电脑。云端不是实时双向文件同步，不会自动覆盖冲突存档。恢复前关闭游戏，程序会另存当前目录。

主界面显眼的“自动监听”控制后台检查；默认关闭。启用后按设置间隔检测游戏启动和退出，发生状态变化才备份。关闭主窗口可留在托盘，托盘可打开、暂停监听和退出。自动备份开始、完成或上传失败时显示通知，可关闭；Windows 通知设置可能影响实际弹出。

项目按 MIT 许可提供，第三方组件许可随安装包提供。配置中的 DAV 密码、DeepSeek Key 使用当前 Windows 用户的 DPAPI 保存，不能直接复制到其他电脑解密。存档内容不发送给 DeepSeek。联网识别只在相应功能启用和执行时进行。
