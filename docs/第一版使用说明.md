# GameCloudSave V1

双击当前便携版目录的“启动新版.bat”。已导入本机 Playnite 的 51 款游戏及封面。旧版 EXE 保留。

## 游戏卡片

从左到右：启动、游戏设置、云存档、移除。启动默认交给 Playnite；游戏设置可单独指定启动 EXE、存档目录和自定义封面。移除只删除管理条目，保留文件和快照。

搜索支持中文，支持仅已安装筛选。封面滑块、每行数量（0 表示自动）、间隔可以调整，设置按电脑保存。小窗口会限制列数，保持图标可操作。

## 云存档

本机已保存 DAV 连接：http://10.208.190.125:5244/dav/，账号 admin，密码使用本机 Windows 加密。

本轮验证并预设的目录是“电脑/GameCloudSave”。在系统设置中可重新浏览并选择目录。操作方式为：填地址/账号/密码 → 连接/浏览 → 点击文件夹进入 → 选择当前文件夹 → 保存本机设置。

每个游戏只需选择本机存档目录；云端路径自动采用根目录/游戏稳定 ID/快照 ZIP，不用逐个填写。

点击云图标后：
- 保存本地 + 上传：先完成 ZIP，再尝试上传。失败保留本地快照。
- 仅本地备份：只创建 ZIP。
- 补传未上传快照：重新上传本机历史中未成功上传的 ZIP。
- 刷新历史：显示最新快照，点击恢复并确认；恢复前另行备份当前存档。

第一版的历史/恢复读取本机 ZIP，尚未提供云端历史浏览与自动下载恢复。上传任务在后台执行；第一版任务按顺序处理，长时间网络操作期间新的任务需等待。失败快照由用户点击补传。

## 不同电脑

各电脑自动建立独立配置。在新电脑的系统设置手动填写 Playnite 程序目录、游戏库 library 目录、本地快照目录、DAV 地址和凭据。逐个游戏重新选择本机存档和启动路径。

内置 rclone 可用于新电脑，也可以手动选择另一个 rclone.exe。本机凭据不能在另一台电脑上直接解密，需要重新输入。复制到新电脑时保留完整应用目录及共享 data；不要只复制 EXE。

当前目录启动脚本使用 workspace/data。若单独复制 dist/GameCloudSave-V1 作为便携版，则程序默认在该 EXE 同级 data 保存数据；可复制共享 library.json 和 covers，随后在新电脑导入 Playnite 校准安装状态和路径。

## 监听与 AI

监听默认关闭。开启后，需要给游戏配置实际运行 EXE 和存档目录，才能在进程启动/退出时自动备份。

常见目录查找扫描 LocalAppData、Roaming、LocalLow、Documents/My Games、Saved Games 和安装目录常见存档子目录。结果需要手动确认，暂不保证能识别所有游戏。

系统设置提供 DeepSeek 开关、模型名和 API Key；AI 只对已找到的真实候选排序，返回 JSON 后会校验，不能凭空添加路径。没有 API Key 时使用本地规则扫描。AI 设置已接入，但本轮没有真实 API Key，未进行在线推理验证。
