# GameCloudSave V2.4.0

发布日期：2026-10-11。将此前仅在源码版验证的资料补全、封面管理、规范标签、发行日期和手柄改动整合为便携版与安装版。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `GameCloudSave-Setup-V2.4.0.exe` | 普通使用：安装到当前用户，可创建桌面与开始菜单快捷方式，提供 Windows 卸载入口 |
| `GameCloudSave-V2.4.0-Portable.zip` | 完整解压后运行 `GameCloudSave.exe`，无需安装 Python；数据保存在程序旁的 `data` |
| `GameCloudSave-V2.4.0-Source.zip` | 对应源码、构建脚本与文档，供查看、开发及自行构建 |
| `SHA256SUMS.txt` | 上述文件的 SHA-256 校验值 |

默认安装目录为 `%LOCALAPPDATA%\Programs\GameCloudSave`，安装版数据位于 `%LOCALAPPDATA%\GameCloudSave\data`。首次启动按向导设置；Playnite、AList/WebDAV 和 DeepSeek 可跳过。软件包含 Python、Qt 和 rclone，不要求用户预先安装这些运行依赖。

完整操作说明见 [安装与便携使用说明](https://github.com/kalianna12/GameCloudSave/blob/v2.4.0/docs/安装与便携使用说明.txt)，安装目录和便携压缩包也附带 `使用说明.txt`。

## 游戏设置与资料补全

- 游戏卡片原来的齿轮入口整合为三个页面：**存档与云端、游戏封面、游戏资料**。封面查询直接在封面页完成；分类、标签、系列和日期可在资料页单独编辑。
- 左栏新增 **资料补全**。选择要查询的内容，预览新增资料及封面、来源和匹配名称，再应用所选项。
- **只补全缺失内容**，保留已有有效封面、日期、标签、系列及人工编辑。应用时重新检查实时数据，预览后手动填入的内容优先。
- 导入时增加 **仅导入 / 导入并查询** 选择。网络查询限定新导入条目，不会自动将候选结果写入游戏库。
- 查询在后台进行，逐条更新预览，支持停止；当前请求返回后收尾。网络失败时保留现有资料，可重试。

## 名称匹配与发行日期

- 首轮未找到资料的游戏追加二次查询，结合 Playnite 原名、导入来源名称、Steam 商店名称、已有英文名/别名及安装目录线索。首轮成功条目不会走额外重试流程。
- 优化标点、全角、简繁中文、罗马序号与附加版本说明处理；VNDB 结合原文、罗马字、多语言标题和别名评分。
- 标题片段用于发现候选，再与完整名称核对；续作编号、重制版信息和相近候选无法明确区分时保留缺失，避免匹配到其他作品。
- Steam 尚未发行或缺少完整日期时，继续查询 VNDB。VNDB 日期标为 **VNDB（首次发行）**，可能早于 Steam 版本日期；不会由 AI 猜日期，也不会覆盖已有日期。
- “美少女万华镜雪女”短名称的 VNDB 二次匹配已通过公开只读验证。部分作品、短名或外部服务缺资料时仍可能需要手动填写。
- 日期升降序将未知日期放到最后；最近游玩页也遵循选择的排序。加宽排序选项并完整展示卡片日期。

## 分类、标签与长文本

- 来源资料优先：Steam/Playnite 原始标签保留，显示时规范中英文别名并限制最多 6 个有效标签；人工标签允许自定义，仍限制 6 个。
- DeepSeek 仅为缺少有效标签的游戏补充最多 3 个代表性标签，不持续向来源标签追加杂项。主分类、标签和系列可以分别编辑。
- 首页增加按标签浏览，展示有效标签及游戏数量；快捷风格行仍按既有规则生成，主分类与标签保持不同用途。
- 批量确认的长存档路径、候选目录与发行日期显示改善，展开选项前也能查看完整路径。
- AList/WebDAV 设置补充 `/dav/` 地址提示。

## 手柄与视觉

- 内页根据实际网格列数导航，上/下落到对应列的上一行/下一行；鼠标点过卡片按钮后，手柄接管正确的卡片索引。
- 左栏游戏库主页、全部游戏、最近游玩、收藏、系列 **选中即切页**，无需按 A；向右进入当前页第一项。
- 内容首行向上依次进入筛选行、搜索行，避免直接跳过筛选。
- 搜索 A 打开手柄键盘：字母/数字、删除、提交，以及游戏库内中文游戏名、标签和系列词条。中文页不是通用中文输入法。
- 卡片、侧栏、搜索、筛选、自动监听、“仅已安装”和通用按钮的焦点使用同一主题强调色。开关和实心强调色按钮使用外围边框区分焦点与状态。
- 手柄菜单支持查看、启动、收藏和已配置存档的操作；尚未适配的编辑窗口阻止方向/A 误触，B 返回。

## 更新、数据与卸载

更新前退出主程序和托盘。安装版重新运行安装包并选择原安装目录；便携版保留 `data`，覆盖程序和 `_internal` 等运行目录即可。

安装版和便携版数据位置独立，安装不会自动搬移便携库。沿用原库时先备份并退出两版，在同一电脑上手动复制完整数据，再核对本机路径；密码和 Key 使用 Windows 用户加密，跨电脑需要重新配置。

安装版可从 Windows“已安装的应用”或安装目录 `Uninstall.exe` 卸载，保留配置、封面、凭据和备份。便携版退出后自行移除程序文件，保留需要的 `data`。游戏文件和真实存档目录不属于卸载目标。

## 发布验证与限制

发布验证覆盖隔离数据的备份恢复、来源导入、资料预览与只补缺、二次匹配、取消与界面响应、标签日期、长路径、手柄网格/侧栏/焦点，以及实际安装包的首次启动、快捷方式、独立数据和卸载。

已通过 54 项 Python 用例、独立升级检查和 7 个 Qt 界面/输入回归脚本。便携程序完成备份恢复、DPAPI、rclone 与隔离启动自检；实际安装器完成安装、首次设置向导、快捷方式、卸载自清理及个人文件保留验证。此电脑隔离安装约 26 秒、卸载约 5 秒，便携界面启动约 1.40 秒、安装版约 1.50 秒，具体时间因电脑而异。现有 286 个个人数据文件核对未变更。

真实手柄手感和具体云端权限仍取决于设备及配置；路径、资料、批量和导入编辑窗口目前需要鼠标。未匹配条目通过“显示全部查询结果”查看原因，手动核对后再应用或编辑。

源码和构建回溯记录保留在 Git。发行文件不包含个人游戏库、配置、凭据、存档备份或测试数据；随包提供项目源码及第三方许可。
