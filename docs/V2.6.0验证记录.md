# V2.6.0 发布验证

2026-10-21（中国时间）。本次用户明确授权“优化界面性能减少 bug，发行一版并上传”，构建固定便携目录、安装与卸载程序，上传至 `kalianna12/GameCloudSave`。测试使用隔离数据，不启动真实游戏、不恢复或上传个人存档。

## 源码与界面

`scripts/verify_release.py` 使用独立子进程运行回归，Qt 界面逐个执行，日志和结果保存于忽略的 `build/release-2.6.0`。

- 31 组 Python 单元脚本，共 294 项用例通过。覆盖本地备份恢复、退出监听、存档目录规则、多账号/多槽/跨设备、AI 联网结果验证、安装事务、元数据与标签、推荐、双向映射、组件检测和模板。
- 23 组独立界面/流程脚本通过：首页增量更新、推荐局部刷新和内容、云存档状态、空间导航、工具栏、全屏生命周期、组合单键编辑、拖放、录入、映射性能、模型几何、模板、存档筛选/恢复预览、异步图片与页内采集、沉浸控制、三种新布局、启动交接、影院切图、资料补全、时间显示、真实 rclone 本地双设备往返。
- Python 编译和 `git diff --check` 通过。

首页模型专项使用 80 条记录：连续 12 次只变栏目状态，卡片 `dataChanged` 为 0；只改一条价格时为 1；同一轮事件循环内 20 次回调合并为 1 次记录更新；重排保留选中 ID，模型重置次数为 0。消除无效写入和通知，不把该结果表述为真实游戏帧率提高。

近期映射回归仍覆盖三模型、两尺寸、双方向等大、192 次点击、摇杆极限行程和录入隔离。Delete 仍作为可绑定按键，单键删除通过鼠标 × 或编辑弹窗完成。

## 历史测试适配

对原有断言保留检查意图并更新前置条件：

- `test_iteration.py` 提供合法的虚拟 DAV 地址和生成存档，在手动应用前处理已设计的合并回调；不访问真实 DAV。
- `test_taxonomy_v232.py` 依据现有固定标签词库，验证同义词转为“合作”、模型最多三个标签、未分类项缓存和已有资料保护。增加断言确保预览不改原始游戏数据，没有改产品规则去满足旧的动态词库假设。
- `test_library_experiences.py` 游戏菜单使用 Menu；A 启动由专项测试覆盖。星图已有动态星光，不再要求星图无空闲帧，其动画开关与暂停由 `test_immersive_controls.py` 检查。
- 运行器明确把仓库根目录放入 `PYTHONPATH`，解决独立执行存档用例时无法导入共享测试辅助类；子进程日志统一 UTF-8。

## 构建与成品检查

主程序显式打包 vgamepad、ViGEmClient DLL 和模块元数据，继续保留 Qt 网页、视频、Shapes、声音和全部 QML/SVG/JS 资源。驱动仍独立检测和按需安装，构建/测试不安装驱动。许可证随包保留。

成品检查脚本：

- `scripts/test_packaged_library.py --version 2.6.0`：对现有 `dist/GameCloudSave/GameCloudSave.exe` 使用生成数据，自检备份恢复、DPAPI、rclone、八组模板及客户端 DLL；四布局及三模型逐个启动、截图和检查 QML 日志。结果写入 `test-data/portable-v2.6.0/report.json`。
- `scripts/test_packaged_installer.py --version 2.6.0`：在隔离测试目录实际安装，快捷方式也在测试目录，禁止写卸载注册表。验证文件版本、安装清单、源码内容、程序自检、首次向导、安装版数据目录；实际卸载后检查用户文件、数据保留与程序自清理。结果写入 `test-data/v2.6.0-installer-report.json`。
- `scripts/package_release.py --version 2.6.0`：压缩包完整性检查、个人目录/凭据排除与 SHA-256 清单；上传后逐项核对 GitHub 返回的大小和摘要，全部匹配后发布。

真实 `workspace/data` 的 287 个文件在构建前记录 SHA-256，发行完成后复核。成品检测结果与最终摘要以本地忽略的报告为证据。

## 边界

本轮不声称完整通过所有历史脚本或验证所有实际游戏、实体手柄、外网商店与网页来源。没有使用真实账户进行云端恢复；双设备往返使用 rclone 本地后端和生成的测试存档。PS/Joy-Con 仍读取经转换的 XInput；反向映射需要额外的 ViGEmBus 系统驱动。打包自检只加载客户端 DLL，不创建虚拟设备或输出键鼠。
