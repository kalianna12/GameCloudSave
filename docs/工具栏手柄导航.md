# 工具栏手柄导航

2026-10-20，源码修复。此前主界面筛选与工具分成两行甚至三行显示，导航仍将所有筛选/工具视为单行：左右会按声明顺序跨行，上直接跳到搜索栏，下直接返回游戏列表。

现在依据可操作控件的实际位置分行，过滤隐藏、禁用和零尺寸控件。

- 左右只在当前显示行内移动，右端停住；行首向左进入对应页面的侧栏。
- 上下逐行进入相邻行，按横向位置选取最近控件，并保留纵向移动前的列位置，避免往返漂移。
- 从游戏列表向上先进入最靠近内容的工具栏行；最低工具栏行向下返回原游戏内容。
- 窗口缩放、Flow 自动折行及排序/系列选项出现后，下一次导航重新读取行位置。宽屏两列区域顶端对齐，避免左侧筛选浮在右侧折行工具的中间。
- 鼠标或其他方式改变焦点后，下一次手柄移动从该控件当前位置开始；下拉框展开时先由列表接收方向键和 B 返回。

`tests/test_toolbar_navigation.py` 用隔离游戏库、真实 Qt 焦点与 `gamepad.dispatch` 验证 900 / 1100 / 1440 / 1920 像素、主页/全部/系列页面、两行/三行布局、行尾停住、上下列位置往返、内容区域往返、鼠标焦点恢复和下拉框优先级。截图位于 `test-data/toolbar-navigation/wrapped-focus-light.png`。

四种布局的工具栏/个性化导航回归见 `test_experience_navigation.py`，其路径已改为先下到工具所在显示行，再向右进入个性化；网格、侧栏和首游戏恢复回归见 `test_navigation_grid_retry.py`。
