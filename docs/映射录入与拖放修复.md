# 映射录入与拖放修复

2026-10-21，仅修改并测试 `workspace` 源码。

## 模型尺寸

原先反向模式为容纳额外选项增加了 44 像素面板高度，正向没有，模型又按可用空间等比缩放，因此两方向显示大小不同。现在两个方向都使用原先较大的面板高度，保留三种模型缓存、按键对象、比例和命中位置。界面测试在 1360×980、1040×700 下分别切换 Xbox、PS、Joy-Con，三次往返测量模型与面板尺寸一致。

## 录入输入

点击“录入组合键”后，专用提示隔开编辑操作，按键或组合全部松开后提交。Enter、数字键盘 Enter、方向键、Tab、Esc、Space、F11、左右修饰键以及鼠标左/右/中/两侧键、滚轮上下都通过录入窗口的事件过滤处理；不会同时点击按钮、移动焦点或修改下拉选项。后续按用户要求取消了本页的手柄导航，B/Back/Menu 与摇杆也参与录入，不保留取消快捷键；只能鼠标点击“取消录入”。正向手柄可选择输入目标，反向可录入手柄输出组合，见 [输入与首页续修](手柄输入与首页交互修整.md)。

滚轮可与 Ctrl 等组合录入，短暂消费同次滚动的后续事件，避免首个刻度完成后剩余刻度突然滚动界面。取消时消费已按住键的后续重复与释放；窗口失焦、最小化、关闭或更换映射方向会取消本次录入。事件只处理已绑定的录入窗口，不使用遍历任意 QML 对象的 `window()` 判断。正常编辑、鼠标点击和预览在录入结束后恢复。

## 拖动位置

拖动命中点仍在鼠标指针，徽标绘制在指针侧上方，不再用整颗宽键帽盖住目标；接近窗口边缘时换侧。“绑定到”提示使用不获取焦点的浮层，避免被 ScrollView 裁切，按键本身继续用主题色高亮。

另定位到 `mapToItem` 的计算没有自动订阅祖先布局和滚动位置，初始化时得到的坐标会过期。提示在显示时读取最终位置，显示期间每 16 毫秒校正，仅当前拖动目标启用计时。截图 `test-data/input-mapping/drag-mouse-target.png` 验证 LT 拖到鼠标右键时徽标、目标框和名称一致。
