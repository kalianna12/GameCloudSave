# 手柄输入与首页交互修整

2026-10-21，仅修改 `workspace` 源码。保留真实配置、游戏库和存档，不打包、覆盖便携版或发布。

## 录入页

映射编辑器只用鼠标操作，删除“手柄导航界面”开关及对应方向导航；打开编辑器恢复可见鼠标。主库的手柄命令在此窗口立即被消费，包括 B、Back、Menu，不再关闭录入、弹窗或窗口。

录入时，正向按手柄选择输入目标，键鼠录入输出；反向按键鼠录入输入，按手柄录入输出组合。支持当前 XInput 可读取的面键、十字键、肩键、扳机、摇杆按下/方向及键鼠组合，不把 B/Menu/Esc 留作取消。全部松开后提交，只能鼠标点击取消按钮；仍保留窗口失焦/关闭时取消和输入释放清理。未新增 XInput 不暴露的系统/Home、触摸板、陀螺仪或原生 HID 输入支持。

手柄录入消费采集线程缓冲中的每个按下/释放边沿，即使 GUI 合并帧后已经松开也可录到短按。正反向配置的语义保持分离，不把手柄 token 存到键盘输出字段。全局 Ctrl+Alt+F12 停止仅在普通运行时生效，录入期间作为组合的一部分，不打断录入。

## 首页导航、按键和反馈

默认首页原先上下仅切换栏目索引，目标栏目保留自己上次选中的卡片。现在使用当前卡片在屏幕上的中心 X，按目标行的卡片宽度、间隔和当前横向滚动位置选择最近项。最近游玩的大图预览、不同宽度的推荐横图与竖版游戏卡片均参与实际坐标计算。左右仍按当前行移动。

筛选区靠左，映射方案、布局、个性化和全屏靠右，贴齐游戏内容边缘；窄窗自然换行，不靠固定占位空格或等分网格居中。工具栏导航继续按可见行与实际位置计算。

游戏内容中的 A 直接启动；Menu 打开游戏菜单，菜单新增“游戏设置”入口；Y 打开真实存档记录，X 收藏，B 返回。分类/系列卡片 A 仍进入相应分组，推荐卡片 A 仍打开官方商品页，顶部控件 A 仍确认当前控件。四种布局使用同一语义，搜索键盘 Menu 仍为完成搜索。底部提示与操作一致。

右摇杆驱动当前选中卡片的倾斜，带死区，松杆、切回鼠标、失焦或关闭动效时复位。个性化提供独立开关；星图保留原有右摇杆缩放，不同时倾斜。弹窗中卡片退出内容焦点，避免背景卡片继续响应。

手柄导航轮询改为 16ms 精确计时器，首次重复等待 280ms、持续重复 85ms；断开时 500ms 重试。首页横向/纵向滚动缩短为约 115/120ms，关闭动效立即移动。不重复遍历同一次导航中的弹窗树，缓存同时考虑窗口及当前焦点。游戏菜单和存档页关闭不再等待 Material 默认长退场，避免下一按键被正在退出的弹窗吞掉。

## 提示音与模型

制作三套原创短音效：清脆、柔和、电子，每套含移动、确认、返回、打开菜单，共 12 个本地 PCM 文件，时长 45～140ms。参考主机界面短促、分层的反馈，不提取或复制 Nintendo 音频。用 `QSoundEffect` 预加载，导航时不重新读取文件；默认应用内音量 80%，个性化可调 0～100%，不修改 Windows 主音量。生成脚本为 `scripts/generate_navigation_sounds.py`。拖动音量时只试听，松开后保存，避免每次移动都提交设置任务。

模型继续使用预载 SVG 与原有按键对象，细化 Xbox 壳体、摇杆环与分享标识，PS 触摸板、分离十字键、握柄与扬声器，Joy-Con 渐变壳体、滑轨、肩键及按键层次；不恢复昂贵 Canvas 模糊阴影。两个映射方向仍使用相同大尺寸。

## 《天津罪》鼠标跳选项

用户反馈游戏没有手柄开关，但支持键盘操作。只读核对当前 01/VN 配置：左摇杆为鼠标、无轻重推附加键，右摇杆为滚轮；没有改动这份配置。算法检查覆盖左摇杆八方向和轻重推，未输出任何键盘键或滚轮。另只读发现 Steam 正在运行，但这不能证明 Steam 桌面布局已启用映射。

游戏内才跳选项，仍可能来自游戏读取实体手柄、Steam Input/桌面布局的第二套输入，或旧游戏重定位 OS 光标。新增“菜单定位（视觉小说）”方式，以独立累计的绝对坐标输出，避免游戏重设指针后相对位移基准跟着跳走；实际鼠标移动时重新接管，失焦/停止清理位置。保留“相对移动（视角）”供 FPS/TPS 使用。绝对坐标按虚拟桌面物理像素换算，包含负坐标副屏，避免把 Qt 逻辑像素当物理像素。

新的 VN 模板默认菜单定位；旧 `templateId=vn` 配置缺少该字段时只补这个默认值，保留原有按键、左右摇杆模式及灵敏度；已有明确选择不会覆盖。可在映射详细设置的鼠标方式中修改，保存后生效。

菜单定位不会屏蔽实体手柄。若仍跳动，应先检查 Steam 控制器的桌面布局或另一套映射。不能关闭游戏原生输入时，兼容性页可打开已安装的 HidHide 工具，或打开[官方配置指引](https://docs.nefarius.at/projects/HidHide/Simple-Setup-Guide/)；此工具通过隔离设备解决双输入，需要额外驱动和手动配置。只允许所需游戏/应用的做法与全局规则限制见[官方 CLI 说明](https://docs.nefarius.at/projects/HidHide/CLI-Usage/)。本轮未安装 HidHide、未改设备隐藏状态、未关闭 Steam、未修改游戏文件。

Windows 相对/绝对鼠标输入含义见 [Microsoft MOUSEINPUT 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)。本轮用自有窗口模拟游戏重设光标并验证真实绝对输出，没有启动《天津罪》本体，不能将该游戏的实际问题报告为已实测解决。
