# 组合按键编辑与键帽样式

2026-10-21，源码迭代。

## 操作

当前绑定的输出组合由纯文字改成独立键帽：

- 点键名，搜索并选择替代按键，原位置直接替换。
- 点键帽右侧 ×，仅删除这一键。例如 `A + Y + X` 删除 X 后保留 `A + Y`。
- 原来的“清空”仍清空整组，录入组合键和拖动追加仍可使用。

普通手柄按键、摇杆轻/重推八方向与附加键均使用同一编辑组件。反向映射分别显示输入组合和输出组合，均可逐键操作；修改输入不会新建另一条绑定或清空输出。输入成员删空时暂不触发，再点上方键盘/鼠标添加输入会保留原输出。替换为已存在成员时去重，保留其余成员和顺序。

编辑列表按映射方向提供键盘/鼠标或者手柄输入，含滚轮、鼠标五键、全部现有虚拟键范围及摇杆轴方向。切换绑定、配置、模型后关闭旧弹窗，避免对新对象误改。录入期间关闭这些编辑入口；没有增加键盘 Delete 删除快捷键，录入 Delete 仍表示绑定 Delete。

12 键组合自动换行，预览内容多时左右面板共同增高，外层滚动可访问全部内容。两种映射方向使用相同基础面板尺寸，小窗口也保留完整模型。

## 按键外观

继续按用户实拍参考细化内部按键。Xbox 使用高光黑色键帽、彩色字母；PS 用矢量路径绘制四个几何符号，方向键改圆角、弧面渐变；Joy-Con 使用黑色字母键和立体加减符号。Xbox / PS 摇杆帽加入橡胶纹理及凹面，Joy-Con 使用哑光圆帽。保持前轮壳体、展开肩键、触发区域和摇杆行程约束。

新纹理为本地缓存 SVG，无网络下载或逐帧重新绘制。模型仍复用固定 16 个交互对象。
