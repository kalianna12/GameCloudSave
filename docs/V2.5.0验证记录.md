# V2.5.0 发布验证

日期：2026-10-17（电脑中国标准时间）。范围为 V2.4.0 之后的源码和 V2.5.0 构建流程，不启动真实游戏，不恢复或上传真实存档。

## 源码检查

126 项 Python 用例通过：

- 78 项：时间显示、退出监听与自动备份、安装事务与数据保护、补全与背景、二次资料查询、规范日期/标签、手动补全、Playnite 媒体、启动窗口检测、材质偏好和图片搜索。
- 48 项：基础备份恢复、来源扫描与同步、游戏库、多个存档槽、初始设置和导入。引导页独立隔离数据检查也通过。

12 组独立脚本通过：安装升级、异步候选、页内网页图片采集、时间显示、全屏/手柄/材质/动态星图、四种布局导航、启动动画与隔离真实子窗口交接、书柜/影院/星图完整交互、卡片悬停、影院双缓冲、本地视频帧解码、资料补全 UI。

脚本分别为 `test_installer_upgrade_v231.py`、`test_async_artwork.py`、`test_inline_artwork_ui.py`、`test_time_ui.py`、`test_immersive_controls.py`、`test_experience_navigation.py`、`test_launch_ui.py`、`test_library_experiences.py`、`test_cover_motion.py`、`test_cinema_backdrop.py`、`test_cinema_video.py`、`test_ui_enrichment.py`。

书柜旧回归脚本在窗口激活/鼠标重新进入的前置状态不明确时出现悬停断言失败；明确激活测试窗口并从封面外重新进入后，完整回归通过。保留原交互断言，没有更改产品的悬停判定。

这不是全量历史脚本通过声明。历史分类测试的已记录基线不兼容见 [焦点全屏与书柜星图优化](焦点全屏与书柜星图优化.md)；本轮未调整分类实现来迎合这些旧断言。

## 构建与成品检查

主程序、安装器与卸载器文件版本统一为 2.5.0。构建显式包含 `PySide6.QtMultimedia` 和 `PySide6.QtWebEngineQuick`，避免新布局和页内浏览依赖仅在开发环境存在；源码压缩包新增保留 `.js`，包括 `ExperienceData.js` 与 `WoodMaterials.js`。

`scripts/test_packaged_library.py` 使用独立数据和生成的封面运行现有 `dist/GameCloudSave/GameCloudSave.exe`，检查打包自检、四种布局启动与截图、错误日志，以及网页/视频运行文件。不会创建另一份便携程序或读取个人凭据。结果保存在 `test-data/portable-v2.5.0/report.json`。

`scripts/test_packaged_installer.py --version 2.5.0` 在独立测试目录实际安装，快捷方式也写入测试目录，使用 `--no-register` 避免修改个人卸载注册表。验证安装清单、打包备份恢复、首次向导、安装版外部数据位置、源码内容一致性，再运行真实卸载器检查程序自清理与用户文件保留。结果保存在 `test-data/v2.5.0-installer-report.json`。

`scripts/package_release.py --version 2.5.0` 检查三个发行输入、ZIP 完整性、个人数据与凭据目录排除，并生成 SHA-256 校验清单。发布上传按文件大小、上传状态和 GitHub 返回的摘要核对。

构建日志、源脚本结果与个人数据前后摘要保存在忽略的 `build/release-2.5.0`；截图和测试数据不进入源码或发行包。真实库 `workspace/data` 在发布准备前记录文件摘要，完成后再次核对。

## 实测边界

没有测量真实游戏的 FPS，没有启动用户游戏，也没有操作真实 DAV 目录。右摇杆与导航用原始 Pad 状态及模拟命令测试；实体手柄手感、外网搜索和各视频插件的适配取决于具体设备及来源。启动交接确认窗口可见和稳定，不识别渲染第一帧。
