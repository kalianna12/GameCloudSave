# V1.1 使用与测试

2026-10-06，香港时间。关闭旧版窗口后，双击当前目录“启动新版.bat”。标题应显示 GameCloudSave · V1.1。

## 本轮变化

图标采用固定中心、等宽操作区域，添加悬停/按下动效。云图标区分本地保存、上传中、成功和失败，快照窗口也展示上传状态；补传同样更新状态。新快照和恢复操作自动刷新本机历史。

封面滑块带 196/240/280/320/360 节点，拖动时逐像素改变封面宽度，并切换“每行”为自动。指定列数时按窗口宽度排布；小窗口限制最低卡片尺寸。窄窗口把布局设置分成两行。

滚动使用固定解码尺寸的 JPG 缩略图缓存、视图对象复用和较大的预加载范围。缩放不重新解码封面，保存布局和云设置不会重建游戏列表。缩略图按源文件指纹更新，换封面时使用新缓存地址。

## 云端存储

主界面顶部“云端存储”或左侧云图标打开独立窗口。最上方显示已保存的位置，左侧直接展示“云端存储文件夹”。

1. 连接地址、用户名和密码可单独填写；现有 AList 凭据已加密保存在本机。
2. 点击“测试连接 / 浏览根目录”，右侧列出目录与文件。
3. 双击文件夹进入，使用“上一级”或地址栏导航。
4. 点击“使用当前浏览文件夹”，再点击“保存云端存储设置”。

预设仍为“电脑/GameCloudSave”，所有游戏自动按稳定 ID 建子目录。单击文本文件可预览前 32KB；4MB 以内的小图片可预览；其他类型显示名称、大小、时间和路径。ZIP 不自动解压。rclone 路径放在“高级”设置，换电脑时可以手动选择。

## 游戏启动

游戏齿轮设置提供“直接启动”和“通过 Playnite”两种方式。直接启动支持 EXE、启动参数和工作目录，留空工作目录时使用 EXE 所在目录。

本轮从之前保存的 Playnite 只读副本检查启动动作，补入 24 款具备可用 EXE、单一文件启动动作、无单独启动脚本的游戏。没有可靠启动动作的游戏继续使用 Playnite，用户可以手动选择 EXE 并切换直接启动。Steam 等平台游戏仍可能由游戏自身启动对应平台客户端。

当前 Playnite 正在占用数据库；重新导入时会提示关闭 Playnite 后再导入，现有清单不受影响。本轮没有关闭 Playnite，也没有实际启动游戏进行验证。

## AI 匹配

主界面顶部“AI 匹配”、左侧星形图标或游戏设置中的按钮打开独立匹配窗口。Key 按电脑与 Windows 用户加密保存，不进入 Git。

可匹配当前游戏或批量匹配已安装游戏；批量操作可停止，正在执行的请求结束后停止后续游戏。左侧保留结果，右侧显示识别名称、别名、候选目录、参考评分、文件样本、模型目录建议核查、耗时和失败原因。

DeepSeek 识别名称与常见存档目录建议，本地再验证路径存在。仅发送游戏名和安装文件夹名称，不发送存档文件内容。路径存在不能证明一定是正确存档，所以结果先显示“待确认”；点击“确认使用此存档目录”后保存到本机，显示“已设置”。未找到时可以手动选择。

真实 API 测试采用 deepseek-flash：
