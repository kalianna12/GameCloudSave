# GameCloudSave V2.5.0

发布日期：2026-10-17（中国时间）。将 V2.4.0 之后的游戏库布局、退出自动备份、页内图片搜索、启动过渡、全屏和手柄修复整合为正式安装版与便携版。

## 下载和更新

| 文件 | 用途 |
| --- | --- |
| `GameCloudSave-Setup-V2.5.0.exe` | Windows 安装版，带桌面/开始菜单快捷方式与卸载入口 |
| `GameCloudSave-V2.5.0-Portable.zip` | 完整解压后运行 `GameCloudSave.exe`，无需安装 Python |
| `GameCloudSave-V2.5.0-Source.zip` | 对应源码、构建脚本、测试和文档 |
| `SHA256SUMS.txt` | 安装包、便携包、源码包的 SHA-256 校验值 |

更新前退出主程序和托盘。安装版运行新安装包并选择原安装目录；默认程序目录为 `%LOCALAPPDATA%\Programs\GameCloudSave`，数据在 `%LOCALAPPDATA%\GameCloudSave\data`。便携版保留 `data` 后覆盖程序文件和 `_internal`。两版数据独立，不自动搬移游戏库；密码和 Key 使用 Windows 用户加密，跨电脑需重新配置。

## 四种游戏库布局

- **原版**继续作为默认布局，保留熟悉的首页和游戏网格。精简封面下方的来源、安装状态等常驻文字；首页封面大小、间距和最近游玩预览可调整，个性化页支持滚动。
- **书柜 SHELF**：封面与书脊两种陈列，选中抽书；书名放到层板铭牌，预留拿起空间。可选橡木、胡桃木、樱桃木及日光，层板加入厚度、拼缝和缓存木纹；书脊感应区与实际可见区域一致。
- **影院 CINEMA**：本地缓存横幅背景、分类胶片导航和更大的竖版封面。切换图片时双缓冲并预载相邻横幅，修复短暂闪出封面、重复选中框及高亮不明显的问题。优先使用已有 Playnite 媒体，发现可用预告时支持主动播放、默认静音。
- **星图 ATLAS**：拖动平移、滚轮或 Xbox 右摇杆缩放，游戏节点按星座轮廓排布；分组配色、关系线、星云、漂移星光和偶发流星。系列按发行顺序排列，可按年份分组。关闭动效、窗口隐藏/失活、游戏运行和启动过渡期间暂停背景动画。
- 书柜、影院、星图可按类别、系列、标签等分组。骰子从当前范围抽游戏，书柜中抽到的书会拿起；支持仅已安装或未玩范围。

布局在“个性化”中选择，配色与布局可分别调整。动效可关闭；木纹和星云使用有界缓存，避免每帧重绘纹理。

## 封面、横幅与资料补全

- 单游戏设置第二页改为 **封面与横幅**，两类图片独立搜索、预览和更换，支持本地图片及图片链接。
- Steam、VNDB 候选在当前页显示，并提示是否有横幅；Google、Bing、IGN 等既有网页来源改为应用内载入、采集图片和预览，不再必须跳到外部浏览器。网页结构、访问限制或网络异常可能导致采集失败。
- 查询后台执行，候选先显示，最多 4 个详情线程逐项补齐资料和横幅；旧查询取消后忽略迟到结果，避免慢详情阻塞整个结果列表。
- 左栏“资料补全”增加横幅和同页手动搜索；未匹配的游戏可以修改关键词、选择候选或手动填写，再加入预览。封面和横幅分别展示，影院胶片使用竖版封面并裁满。
- 新增“仅显示缺失项”，系列空白不作为缺失条件。保持 **只补缺、不覆盖**；候选先预览，应用时再次检查已有资料和人工编辑。
- 仅对首轮未完成的条目追加名称变体、繁简字和别名匹配。Steam 日期不足时继续查 VNDB；DeepSeek 辅助识别名称和分类，不编造发行日期。版本或续作不明确时保留缺失，供手动核对。

## 退出自动备份

- 监听采用低频后台进程采样，默认每 5 秒一次；游戏运行时不持续压缩或上传存档。
- 每次检测到游戏结束后排队执行一次自动备份，忙于其他任务时也保留退出任务。上传失败保留本地备份，可重试，不重复生成同一次退出的压缩包。
- 默认每款游戏保留最近 **5 份本机自动备份**，可在设置调整。仅清理超限本机自动备份，**手动备份不限制，云端版本保留**。
- 存档记录与云端文件预览按电脑系统时区显示；中国标准时间下，`2026-10-16T12:53:17+00:00` 显示为 `2026-10-16 20:53:17`。底层时间及原有备份数据保留。

## 手柄、全屏和启动

- 工具栏与 F11 可切换全屏，并保存偏好。关闭个性化、B 返回、X 收藏、托盘唤醒和重复启动不会意外退出全屏；主动退出恢复原窗口尺寸。
- 四种布局补齐顶部个性化、分类、游戏列表和操作按钮之间的导航。右摇杆缩放只在星图内容区域生效，并带死区、滞回和重复节流。
- 选中框统一跟随强调色；修复鼠标点击后两个框和手柄切换时焦点残留。卡片倾斜连续跟手，输入模式切换、离开或滚动时复位。
- 游戏启动时完整播放约 900 毫秒过渡动画，同时后台启动游戏；等待游戏窗口稳定可见后交接。支持返回和超时后继续等待，不重复启动游戏。此检测针对可见窗口，不等同于识别游戏实际渲染的第一帧。
- 搜索处仍可用手柄打开应用内键盘。复杂目录和资料编辑继续以鼠标为主；模拟输入验证不替代真实 Xbox 手柄手感测试。

## 安装、卸载和数据

安装器包含 Python、Qt、内嵌网页/视频所需组件、rclone、卸载程序、许可证和源码。安装到当前 Windows 用户，无需预先安装 Python。

Windows“已安装的应用”或程序目录 `Uninstall.exe` 可卸载安装版，保留用户配置、封面、凭据与备份；游戏文件和真实存档目录不属于卸载目标。便携版退出后移除程序文件即可，先保留需要的 `data`。

发行文件不包含个人游戏库、配置、API Key、密码、存档或测试数据。完整操作说明随包提供，见 [安装与便携使用说明](https://github.com/kalianna12/GameCloudSave/blob/v2.5.0/docs/安装与便携使用说明.txt)。
