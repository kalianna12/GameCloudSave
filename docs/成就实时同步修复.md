# 成就实时同步修复

2026-10-24，仅修改与测试 workspace 源码，未打包或同步便携版。

## 原因与修改

- 原监听只在游戏库启动游戏、且识别到游戏窗口后读文件。现在已配置记录在后台约每秒检查，等待独立启动器时也可同步；直接启动游戏可以同步统计，但游戏内弹窗仍需要游戏库确认对应窗口。
- 原文件变化只在当次刷新详情，页面忙碌时会丢弃刷新。现在合并实时进度、保留搜索中的状态和候选版本，封面计数与统计总览同步更新。
- 原签名只有记录文件属性；SSE 等记录在定义到达前无法对应内部编号，之后同一文件会被跳过。现在签名包含定义编号，同时保留首次原始基线，避免补齐定义时重播旧解锁。
- 文件断写、原子替换、暂时消失、读取失败保留历史并自动重试。即使一次后台检查发生异常，也会释放检查中的标记。
- 成就页增加监听状态，区分后台同步、尚无记录、多个账号、读取失败与关闭监听。

已知文件每秒仅检查属性，变化后才解析；仅当前选中或启动中的未匹配游戏每隔约 8 秒进行有范围限制的发现，不扫描全库目录。网络和图标任务继续独立于记录线程。
