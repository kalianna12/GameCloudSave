# 主题修整与横幅补全

2026-10-16，源码迭代。原版仍是默认布局，真实游戏库、设置和存档未由测试改写；便携版及安装包未更新。

## 书柜

书名位于木层板内的深棕铭牌，使用米白字，选中时变为金色描边。层板加高，封面和分类标题之间保留抽书空间；封面、文字、层板不再叠在一起。长标题保留文字悬停提示及底部完整名称。

再次修整：每层增加 36 像素抽书留白，书本感应区收紧到实际封面或书脊，不再包含上方、右侧和铭牌下方空白。书脊收起时完全隐藏旋转封面，消除右侧细纸片；抽出时才显示封面。

## 星图

- 分组保留类别、系列、标签、不分组，增加发行年份。使用现有库字段，不另造分类；标签模式优先选择较具体的共享标签安置节点，一款游戏只显示一次。
- 每个节点为封面、两行名称、日期分别预留区域；替换交错行，按五种星座轮廓和较大收藏的螺旋扩展生成稳定位置，并避让封面与文字。分组也采用环绕位置，不再排成矩形表格。九个内置类别各有固定颜色，自定义系列和标签使用稳定颜色。
- 默认按发行日期从早到晚排列，也可从晚到早或按名称。系列成员按所选顺序连线，未知日期始终在末尾；没有真实分组资料的节点不制造关系。年份分组按年份排列。
- 选择节点时镜头平滑移动，当前关系线短暂变亮。骰子触发一次金色光环和星芒，并显示“幸运之选”；仍遵守当前筛选范围，不会自动启动游戏。
- 类别与标签连接邻近且真实关联的成员，系列和年份仍按所选日期顺序连接。每款游戏只保留一个节点，没有无依据的跨类关系。
- 星空增加蓝紫、青色星云、气体纹理和缓慢漂移/明暗变化。背景画布只在尺寸变化时重绘，平时移动缓存纹理，以 80 毫秒间隔推进；分组星云纹理上限 640×640，避免大库产生巨型纹理。拖动有背景视差；关闭动效、窗口失活/隐藏或检测到游戏运行时暂停。此项响应本轮背景动效要求，替代之前的全静态天空。

## 影院与横幅

底部胶片带增加类别栏，点击即可切换当前分组；分组下拉框仍可用于手柄操作，也可换为系列、标签或年份。

胶片带恢复使用竖版游戏封面，比例随胶片带高度调整，按区域裁满，去掉原来横幅在缩略图框内的上下空边。补全得到的横幅仅用于影院大背景。补全结果右侧也以封面为主，横幅另作较小预览，不替换封面。

横幅采用两张图片缓冲，新图就绪后短暂过渡；快速切换合并加载请求，只预载相邻三张。尚未就绪时保留画面并使用封面兜底。预告仍需主动播放，切游戏、离开或启动时停止。

在“资料补全”中勾选“横幅背景”，查询后查看横向预览，再应用所选结果。导入后的补全流程也包含此选项。优先读取 Playnite 背景，其次读取匹配游戏的 Steam 背景或 VNDB 截图；下载、校验和缩放在工作线程进行，缓存为最长 1280 像素宽的本地 JPEG。只补缺失图片，应用时再次检查，保护查询期间新设置的背景。

本地缓存和相邻预载减少影院切换时的网络等待；首次在线查询仍受网络影响，不保证未经补全的在线横幅首次打开即就绪。

## 同页手动补全

默认显示全部查询结果，查不到的游戏也有“手动搜索与补全”入口。点击后在同一窗口里修改搜索名称、搜索和核对候选；选择候选会把资料库日期、标签、缺失图片加入原预览。也能直接填写缺失日期、分类、标签、系列、图片链接或本地图片。

搜索沿用原来源：Steam、VNDB、自定义 JSON 直接显示候选；Google 图片、Bing 图片、IGN、SteamGridDB、GOG 和 Epic 按原约定在浏览器检索，查得的日期和图片链接可填回同页表单。浏览器网页不会被冒充为结构化资料，也不抓取登录内容。

点击“加入补全预览”后返回原查询列表，最后“应用所选补全”才写入游戏库。现有或查询期间新增的资料不会被覆盖；手工填写的日期、标签、分类和系列记录手动标记。下载及读取候选资料仍在后台进行。重复的下载失败提示合并显示，未查到的项目直接列出仍缺哪些资料。

## 发行日期漏查原因

本机只读核查的真实库有 52 款游戏，其中一款缺日期：`真爱の百合は赤く染まる`。原查询使用简体“爱”，VNDB 收录的日文名称为 `真愛の百合は赤く染まる`。原关键词返回零条，改用“愛”后，官方 API 返回 [VNDB v26232](https://vndb.org/v26232)，首次发行日期为 **2019-11-08**。

修复包含繁简体关键词二次查询，并让缺日期等未完成项也能请求 DeepSeek 提供别名，然后重新核对资料库。原来已有名称匹配但缺日期时，可能跳过这一步。负结果缓存缩短为 5 分钟，并更新缓存版本，避免旧的漏查长期复用。

日期仍以资料库完整日期为准，DeepSeek 辅助识别名称和分类，不将模型猜测写成日期。匹配到名称但来源没有完整日期，与未可靠匹配名称，会显示不同原因。查询结果保留来源和名称供预览核对。此次真实请求只产生隔离预览，没有代替用户应用到真实库。

## 验证与体验

双击 workspace 下的 `启动源码版.bat`，在个性化切换书柜、影院或星图。此入口使用 `test-data/source-preview` 隔离数据；上级目录的 `启动新版.bat` 仍可能打开旧便携程序。

通过 9 组界面脚本：新布局、横幅缓冲、视频停止与释放、资料补全、个性化、资料刷新、两组手柄导航、导入及批量确认。截图复核覆盖 900/1440/1920 宽度。通过 57 项后端检查及 5 项布局算法检查，包含图片预览不写库、应用不覆盖、非法图片拒绝、繁简体查询、封面及两行文字空间不相交、日期排序和 2000 款关系计算。`git diff --check` 通过。

隔离截图、日期诊断和界面回归记录在本机 `test-data/experience-review`，不进入 Git 或发行包。真实手柄手感和游戏运行中的实际帧数仍需实际体验，测试未启动真实游戏。

本次再修整验证：7 组界面回归及 68 项后端/布局算法检查通过。增加了书脊空白处不触发、关闭封面不可见、抽书顶部不裁切、星座轮廓稳定且有差异、天空在关闭动效/隐藏窗口/模拟游戏运行时暂停、手动候选及填写先预览后保存、已有数据优先、小窗口表单滚动等检查。另用真实 Steam 公开资料在隔离缓存完成了一次横幅下载校验，没有写入真实游戏库。
